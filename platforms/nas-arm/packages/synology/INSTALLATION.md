# Установка IP-CSS на Synology NAS (ARM)

**Версия:** Alfa-0.1.1
**Дата:** 28 января 2026
**Архитектура:** ARM64 (armv8)

## Системные требования

- **Synology DSM:** 7.0 или выше
- **Архитектура:** ARM64 (armv8)
- **Java:** 17 или выше (обязательно)
- **Node.js:** 18+ (опционально, для веб-интерфейса)
- **Свободное место:** минимум 500MB
- **RAM:** минимум 2GB

## Подготовка

### 1. Установка Java

Java является обязательным требованием для работы API сервера.

**Вариант 1: Через Package Center (рекомендуется)**
1. Откройте Package Center на вашем Synology NAS
2. Найдите "Java Manager" или "Java"
3. Установите Java 17 или выше для ARM64

**Вариант 2: Ручная установка**
1. Скачайте Java для ARM64 архитектуры
2. Установите через Package Center → Ручная установка

**Проверка установки:**
```bash
ssh admin@your-nas-ip
java -version
# Должно показать: openjdk version "17.x.x" или выше
```

### 2. Установка Node.js (опционально)

Node.js требуется только для веб-интерфейса. Если Node.js не установлен, пакет будет работать только с API сервером.

**Вариант 1: Через Package Center**
1. Откройте Package Center
2. Найдите "Node.js v18" или выше для ARM64
3. Установите Node.js

**Вариант 2: Через SynoCommunity**
1. Добавьте источник пакетов SynoCommunity
2. Установите Node.js через Package Center

**Проверка установки:**
```bash
ssh admin@your-nas-ip
node -v
# Должно показать: v18.x.x или выше
```

## Установка пакета

### Шаг 1: Скачивание пакета

1. Скачайте файл `.spk` пакета для ARM архитектуры:
   - `ip-css-Alfa-0.1.1-synology-arm64.spk`

### Шаг 2: Установка через Package Center

1. Откройте **Package Center** на вашем Synology NAS
2. Нажмите **"Ручная установка"** (Manual Install)
3. Выберите скачанный `.spk` файл
4. Нажмите **"Далее"** (Next)
5. Следуйте инструкциям установщика

### Шаг 3: Проверка установки

После установки пакет должен автоматически запуститься. Проверьте статус:

1. Откройте Package Center
2. Найдите "IP Camera Surveillance System"
3. Убедитесь, что статус показывает "Запущен" (Running)

## Доступ к приложению

После успешной установки:

- **Web UI:** http://your-nas-ip:8080 (если Node.js установлен)
- **API:** http://your-nas-ip:8081

Замените `your-nas-ip` на IP-адрес вашего Synology NAS.

## Устранение неполадок

### Ошибка: "Java is not installed"

**Проблема:** Java не установлен или не найден в PATH.

**Решение:**
1. Установите Java через Package Center (см. раздел "Подготовка")
2. Убедитесь, что Java установлена в системный PATH
3. Перезапустите установку пакета

**Проверка:**
```bash
ssh admin@your-nas-ip
which java
java -version
```

### Ошибка: "Java 17 or later is required"

**Проблема:** Установлена более старая версия Java.

**Решение:**
1. Удалите старую версию Java
2. Установите Java 17 или выше для ARM64
3. Перезапустите установку пакета

### Ошибка: "Insufficient disk space"

**Проблема:** Недостаточно свободного места на системном разделе.

**Решение:**
1. Освободите минимум 500MB на системном разделе
2. Удалите ненужные пакеты или файлы
3. Перезапустите установку

**Проверка свободного места:**
```bash
ssh admin@your-nas-ip
df -h
```

### Веб-интерфейс не доступен

**Проблема:** Node.js не установлен или веб-интерфейс не включен в пакет.

**Решение:**
1. Установите Node.js 18+ для ARM64 (см. раздел "Подготовка")
2. Переустановите пакет
3. Проверьте, что порт 8080 не занят другим приложением

**Проверка:**
```bash
ssh admin@your-nas-ip
netstat -tuln | grep 8080
```

**Альтернатива:** Используйте только API сервер на порту 8081

### API сервер не запускается

**Проблема:** Ошибка при запуске API сервера.

**Решение:**
1. Проверьте логи:
   ```bash
   ssh admin@your-nas-ip
   tail -f /var/packages/ip-css/var/logs/ip-css.log
   ```

2. Проверьте, что порт 8081 не занят:
   ```bash
   netstat -tuln | grep 8081
   ```

3. Проверьте права доступа:
   ```bash
   ls -la /var/packages/ip-css/
   ```

### Пакет не запускается автоматически

**Проблема:** Пакет не запускается после перезагрузки NAS.

**Решение:**
1. Откройте Package Center
2. Найдите "IP Camera Surveillance System"
3. Нажмите "Запустить" (Start)
4. Убедитесь, что опция "Запускать при загрузке" включена

## Удаление пакета

### Через Package Center

1. Откройте Package Center
2. Найдите "IP Camera Surveillance System"
3. Нажмите **"Удалить"** (Uninstall)
4. Подтвердите удаление

**Примечание:** По умолчанию данные (записи, база данных) сохраняются. Если вы хотите удалить все данные, удалите директорию вручную после удаления пакета:

```bash
ssh admin@your-nas-ip
rm -rf /var/packages/ip-css/var
```

## Конфигурация

### Расположение файлов

- **Установка:** `/var/packages/ip-css/target`
- **Данные:** `/var/packages/ip-css/var`
- **Конфигурация:** `/var/packages/ip-css/etc`
- **Логи:** `/var/packages/ip-css/var/logs`

### Изменение конфигурации

1. Отредактируйте файл конфигурации:
   ```bash
   ssh admin@your-nas-ip
   nano /var/packages/ip-css/etc/config.yaml
   ```

2. Перезапустите пакет:
   ```bash
   /usr/syno/bin/synopkg restart ip-css
   ```
