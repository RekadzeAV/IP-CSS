## Обоснование

В ходе структурного аудита проекта (июнь 2026) выявлены системные проблемы:
- Расхождение документированной и реальной структуры модулей
- Множественное дублирование кода (Model/DTO, репозитории)
- Засорение репозитория аварийными дампами и мёртвыми директориями
- Раздутая документация (~200 файлов, из них ~50% устаревших)

## Структура архива

```
archive/
├── docs/                          # Устаревшая документация
│   ├── api/                       # Старые API-документы
│   ├── deployment/                # Старые руководства по деплою
│   ├── onvif/                     # Устаревшие ONVIF-документы
│   ├── reports/                   # Финальные отчёты
│   ├── phases/                    # Фазовые документы
│   └── meta/                      # Документы о документации
├── modules/                       # Мёртвые модули кода
│   ├── core-license/              # core/license/ (отключён)
│   ├── core-integrationTest/      # core/integrationTest/ (без build.gradle.kts)
│   ├── core-streaming/            # core/streaming/ (без build.gradle.kts)
│   └── core-video-decoder/        # core/video-decoder/ (без build.gradle.kts)
├── repositories/                  # Старые реализации репозиториев
│   ├── impl/                      # *Impl (старые, API-based)
│   ├── sqldelight/                # *ImplSqlDelight (старые)
│   └── transitional/              # CameraCache, CameraRepositoryWithEventMonitoring
├── config/                        # Устаревшие конфиги
│   ├── test-cameras/              # Старые test-cameras*.json
│   └── certificate-pins/          # Дублирующиеся certificate-pins
└── platforms/                     # Неиспользуемые NAS-платформы
    ├── nas-asustor/
    ├── nas-qnap/
    ├── nas-synology/
    ├── nas-truenas/
    └── nas-common/
```
