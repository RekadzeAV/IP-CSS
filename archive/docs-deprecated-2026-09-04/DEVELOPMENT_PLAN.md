## 📝 Заметки

- Проект использует Kotlin Multiplatform, что позволяет переиспользовать код между платформами
- Нативные библиотеки (C++) необходимы для производительности видео обработки
- Важно поддерживать консистентность архитектуры между модулями
- Необходимо учитывать ограничения мобильных платформ (память, батарея)
