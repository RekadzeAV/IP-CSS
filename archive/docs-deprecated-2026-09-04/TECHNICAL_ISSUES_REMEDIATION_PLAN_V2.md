## 2. 🟡 Проблема: Plaintext Пароли Камер - ОБНОВЛЁННО

### Описание:

Ошибка при чтении камер из БД из-за требования шифрования паролей.

### КОНТЕКСТ:

**Рабочий контур наблюдения:**
- ✅ Камеры уже настроены и работают
- ✅ Пароли статичные, не требуют изменений
- ✅ NAS хранилище активно
- ❌ IP-CSS не может прочитать камеры из-за проверки шифрования

### Решение: АДАПТАЦИЯ (не миграция)

Так как пароли не должны меняться, нужно адаптировать IP-CSS к существующим данным.

#### Шаг 1: Отключение Строгой Проверки

**CameraEntityMapper.kt:**

```kotlin
fun toDomain(entity: CameraEntity): Camera {
    val password = entity.password
    
    // Для рабочего контура - принимаем plaintext пароли
    // В production можно включить шифрование для НОВЫХ камер
    if (password.isBlank()) {
        throw SecurityException("Camera password cannot be empty")
    }
    
    // Логируем для мониторинга
    logger.warn("Camera ${entity.id} uses plaintext password (legacy system)")
    
    return Camera(
        id = entity.id,
        name = entity.name,
        rtspUrl = entity.rtspUrl,
        username = entity.username,
        password = password,  // Используем как есть
        enabled = entity.enabled
    )
}
```

**Статус:** ⏸️ Требуется изменение кода

#### Шаг 2: Конфигурационный Флаг

**application.conf:**

```hocon
security {
  # Для рабочего контура - разрешаем plaintext пароли
  allow-plaintext-passwords = true
  
  # Шифрование только для НОВЫХ камер (опционально)
  encrypt-new-cameras = false
}
```

**Статус:** ⏸️ Требуется добавление
