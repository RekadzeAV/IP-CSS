## 📋 Оставшиеся шаги (выполнить вручную)

### 2. Установка clangd

Clangd не найден в системе. Установите его одним из способов:

#### Вариант A: Через Chocolatey (рекомендуется)
```powershell
# Откройте PowerShell от имени администратора
choco install llvm
```

После установки перезапустите VS Code.

#### Вариант B: Скачать вручную
1. Перейдите на https://github.com/clangd/clangd/releases
2. Скачайте последнюю версию для Windows
3. Распакуйте и добавьте в PATH, или укажите путь в настройках VS Code

#### Вариант C: Через winget
```powershell
winget install LLVM.LLVM
```

---

### 3. Перезапуск языковых серверов в VS Code

После установки clangd выполните следующие действия:

#### Перезапуск Clangd сервера:
1. Откройте VS Code
2. Нажмите `Ctrl+Shift+P` (или `F1`)
3. Введите: `clangd: Restart language server`
4. Нажмите Enter

#### Перезапуск TypeScript сервера:
1. Нажмите `Ctrl+Shift+P`
2. Введите: `TypeScript: Restart TS server`
3. Нажмите Enter

#### Альтернативный способ - перезагрузка окна:
1. Нажмите `Ctrl+Shift+P`
2. Введите: `Developer: Reload Window`
3. Нажмите Enter

---

### 4. Установка рекомендуемых расширений

VS Code должен автоматически предложить установить рекомендуемые расширения. Если этого не произошло:

1. Нажмите `Ctrl+Shift+X` для открытия панели расширений
2. Введите в поиск: `@recommended`
3. Установите все рекомендуемые расширения

#### Критически важные расширения:

**Для C++:**
- `llvm-vs-code-extensions.vscode-clangd` - Clangd language server
- `ms-vscode.cpptools` - C/C++ IntelliSense (будет отключен в пользу clangd)
- `ms-vscode.cmake-tools` - CMake поддержка

**Для TypeScript/React:**
- `dbaeumer.vscode-eslint` - ESLint
- `esbenp.prettier-vscode` - Prettier
- `ms-vscode.vscode-typescript-next` - TypeScript поддержка

**Для Kotlin:**
- `fwcd.kotlin` - Kotlin language support

## 🛠️ Решение проблем

### Clangd все еще показывает ошибки:

1. **Проверьте, что clangd установлен:**
   ```powershell
   clangd --version
   ```

2. **Проверьте, что compile_commands.json существует:**
   ```powershell
   Test-Path native\compile_commands.json
   ```

3. **Перезапустите clangd сервер** (см. шаг 3 выше)

4. **Проверьте настройки VS Code:**
   - Убедитесь, что расширение `vscode-clangd` установлено и активно
   - Проверьте, что в настройках `C_Cpp.intelliSenseEngine` установлен в `"disabled"`

### TypeScript ошибки не исчезают:

1. **Убедитесь, что зависимости установлены:**
   ```powershell
   cd server\web
   npm install
   ```

2. **Перезапустите TypeScript сервер** (см. шаг 3 выше)

3. **Проверьте tsconfig.json:**
   - Убедитесь, что файл `server/web/tsconfig.json` существует и корректен

### ESLint не работает:

1. **Убедитесь, что расширение установлено:**
   - `dbaeumer.vscode-eslint` должно быть установлено

2. **Проверьте рабочую директорию:**
   - В `.vscode/settings.json` должна быть строка: `"eslint.workingDirectories": ["server/web"]`

3. **Перезагрузите окно VS Code**
