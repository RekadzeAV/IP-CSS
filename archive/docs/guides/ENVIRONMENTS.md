## 🔄 Связь Между Окружениями

### Local ↔ Network:

| Направление | Протокол | Порт | Статус |
|-------------|----------|------|--------|
| Dev → Cameras | RTSP | 554 | ⚠️ Камеры недоступны |
| Dev → NAS | SMB/NFS | 445/2049 | ⏸️ NAS не настроен |
| Dev → Raspberry Pi | SSH/RTSP | 22/554 | ⏸️ Pi не настроен |

### Docker Network:

```
surveillance-network (bridge)
├── surveillance-postgres (172.18.0.2)
├── surveillance-redis (172.18.0.3)
└── surveillance-api (172.18.0.4)
```

**Port Mapping:**
- 5432:5432 → PostgreSQL
- 6379:6379 → Redis
- 8080:8080 → API (при запуске)

## 🚀 Запуск Окружений

```powershell
# Запуск Docker контейнеров
$env:DB_PASSWORD='ManualCheckDb#2026!Secure'
$env:REDIS_PASSWORD='ManualCheckRedis#2026!Secure'
$env:JWT_SECRET='ManualCheckJwt#2026-SecureRandomValue-For-Local'
$env:DATA_ENCRYPTION_KEY='0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef'
$env:ENVIRONMENT='development'
$env:ADMIN_PASSWORD='admin123'

docker-compose up -d

# Проверка статуса
docker ps

# Проверка PostgreSQL
Test-NetConnection localhost -Port 5432

# Проверка Redis
Test-NetConnection localhost -Port 6379
```

```powershell

.\scripts\discover-rtsp-cameras.ps1 -Subnet "192.168.10.0/24"

# Тестирование камер
.\scripts\test-rtsp-known-cameras.ps1 -ConfigFile config\test-cameras-local-network.json

# Полевая валидация
.\scripts\auto-field-validation.ps1
```

## 📝 Примечания

### Локальное Окружение:

- Полностью функционально
- PostgreSQL и Redis доступны
- API сервер требует сборки

- Сеть 192.168.10.0/24 доступна
- Камеры конфигурированы, но физически не обнаружены
- Raspberry Pi и NAS требуют настройки
- Требуется подтверждение физического наличия устройств
