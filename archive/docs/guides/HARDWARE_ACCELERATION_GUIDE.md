# Руководство по аппаратному ускорению декодирования

## Обзор

VideoDecoder поддерживает аппаратное ускорение декодирования через FFmpeg hardware decoders. Это может значительно снизить нагрузку на CPU и улучшить производительность.

## Поддерживаемые платформы

### Windows
- **NVIDIA CUVID** (`h264_cuvid`, `hevc_cuvid`) - для NVIDIA GPU
- **Intel Quick Sync** (`h264_qsv`, `hevc_qsv`) - для Intel процессоров с iGPU
- **D3D11VA** - DirectX 11 Video Acceleration

### Linux
- **NVIDIA CUVID** (`h264_cuvid`, `hevc_cuvid`) - для NVIDIA GPU
- **VAAPI** (`h264_vaapi`, `hevc_vaapi`) - для Intel/AMD GPU
- **V4L2** (`h264_v4l2m2m`, `hevc_v4l2m2m`) - для различных декодеров
- **MMAL** (`h264_mmal`) - для Raspberry Pi

### macOS
- **VideoToolbox** (`h264_videotoolbox`, `hevc_videotoolbox`) - встроенное Apple ускорение

## Автоматическое определение

VideoDecoder автоматически пытается найти и использовать аппаратный декодер при инициализации:

1. Сначала пробует найти аппаратный декодер
2. Если не найден, использует программный декодер
3. Логирует, какой декодер используется

## Проверка доступности

### Через FFmpeg
```bash
# Проверка доступных декодеров
ffmpeg -decoders | grep h264
ffmpeg -decoders | grep hevc

# Проверка конкретного аппаратного декодера
ffmpeg -h decoder=h264_cuvid
```

### Через код
```kotlin
val decoder = VideoDecoder(VideoCodec.H264, 1920, 1080)
// Проверьте логи - будет указано, используется ли аппаратный декодер
```

## Требования

### NVIDIA CUVID
- NVIDIA GPU с поддержкой CUDA
- Драйверы NVIDIA
- FFmpeg собран с поддержкой CUVID

### Intel Quick Sync
- Intel процессор с iGPU (6-го поколения или новее)
- Драйверы Intel Graphics
- FFmpeg собран с поддержкой libmfx

### VAAPI (Linux)
- GPU с поддержкой VAAPI (Intel/AMD)
- Установленные библиотеки: `libva-dev`, `libva-drm2`, `libva-x11-2`
- FFmpeg собран с поддержкой VAAPI

### VideoToolbox (macOS)
- macOS 10.8+
- Автоматически доступен в FFmpeg для macOS

## Настройка

Аппаратное ускорение включается автоматически, если доступно. Для принудительного отключения:

```kotlin
// В VideoDecoderImpl (внутренний класс)
// Установите enableHardwareAcceleration = false
```

## Производительность

### Ожидаемые улучшения

- **CPU usage**: Снижение на 60-80%
- **Decode time**: Улучшение на 30-50% для высоких разрешений
- **Power consumption**: Снижение на 40-60% (особенно на ноутбуках)

### Зависит от:
- Типа GPU/аппаратного декодера
- Разрешения видео
- Битрейта
- Нагрузки системы

## Устранение проблем

### Аппаратный декодер не используется

1. Проверьте, что FFmpeg собран с поддержкой нужного декодера:
   ```bash
   ffmpeg -decoders | grep cuvid
   ```

2. Проверьте драйверы GPU

3. Проверьте логи - VideoDecoder логирует, какой декодер используется

### Ошибки при использовании аппаратного декодера

Если аппаратный декодер вызывает ошибки, VideoDecoder автоматически переключится на программный декодер.
