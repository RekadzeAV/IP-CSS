## Инструкции по использованию

### Шаг 1: Запуск демо-тестов (без реальных камер)

```bash
# Windows
.\scripts\run-demo-tests.ps1

# Linux/macOS
./scripts/run-demo-tests.sh
```

Это запустит тесты с симулятором, которые не требуют реальных камер.

### Шаг 2: Настройка для реальных камер

```bash
# Windows
. .\scripts\setup-test-environment.ps1

# Linux/macOS
source ./scripts/setup-test-environment.sh
```

Отредактируйте файл `.test-env` с URL ваших камер.

### Шаг 3: Запуск тестов с реальными камерами

```bash
# Windows
.\scripts\test-video-decoder.ps1

# Linux/macOS
./scripts/test-video-decoder.sh
```

### Шаг 4: Анализ результатов

1. Просмотрите логи в `build/test-results/`
2. Экспортируйте метрики из `VideoDecoderMetrics`
3. Заполните отчет используя `docs/TESTING_RESULTS_EXAMPLE.md` как пример

### Шаг 5: Применение оптимизаций

Используйте рекомендации из `docs/OPTIMIZATION_RECOMMENDATIONS.md` для оптимизации на основе результатов.

## Сборка нативных библиотек

### Linux x64

**Требования:**
```bash
sudo apt-get install -y cmake build-essential pkg-config
sudo apt-get install -y libavcodec-dev libavformat-dev libavutil-dev libswscale-dev libswresample-dev
```

**Сборка:**
```bash
./scripts/build-video-processing-linux.sh
```

### macOS x64/arm64

**Требования:**
```bash
brew install cmake ffmpeg
```

**Сборка:**
```bash
# Apple Silicon
./scripts/build-video-processing-macos.sh arm64

# Intel
./scripts/build-video-processing-macos.sh x64
```
