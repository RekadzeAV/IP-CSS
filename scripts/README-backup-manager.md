# Backup Manager

PowerShell-скрипт для управления бэкапами между локальным диском и NAS-хранилищем.

## Функции

1. **Disk to NAS** — резервное копирование с локального диска на NAS
2. **NAS to Disk** — восстановление данных с NAS на локальный диск
3. **Sync** — двусторонняя синхронизация изменений

## Использование

### Интерактивный режим
```powershell
.\backup-manager.ps1
```

### С параметрами
```powershell
.\backup-manager.ps1 -SourcePath "E:\GitHub-Ai\IP-CSS" -DestPath "\\192.168.10.38\Git"
```

## Конфигурация

Пути по умолчанию (изменить в скрипте):
- Диск: `E:\GitHub-Ai\IP-CSS`
- NAS: `\\192.168.10.40\AI-prodgect`

## Зависимости

- Windows PowerShell 5.1+
- robocopy (встроен в Windows)
- Доступ к NAS по SMB

## Примечания

- Использует `robocopy` для надежного копирования
- Поддерживает докачку при обрыве соединения
- При синхронизации копируются только новые и измененные файлы
