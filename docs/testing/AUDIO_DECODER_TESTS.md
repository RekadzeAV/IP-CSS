**Дата:** 27 January 2026

## 📋 Обзор

Unit тесты для проверки декодирования аудио кодеков: AAC, G.711 PCMU, G.711 PCMA.

---

## 🧪 Реализованные тесты

### AAC (Advanced Audio Coding)

#### test_audio_decoder_aac_init
**Назначение:** Проверка инициализации AAC декодера.

**Параметры:**
- Sample rate: 48000 Hz
- Channels: 2 (stereo)

**Проверяет:**
- Успешное создание декодера
- Корректная инициализация

#### test_audio_decoder_aac_decode
**Назначение:** Проверка декодирования AAC кадра.

**Проверяет:**
- Успешное декодирование AAC кадра
- Обработка минимальных тестовых данных

### Дополнительные тесты

#### test_audio_decoder_sample_rates
**Назначение:** Проверка поддержки различных частот дискретизации.

**Тестируемые частоты:**
- 8000 Hz
- 16000 Hz
- 44100 Hz
- 48000 Hz

**Проверяет:**
- Успешная инициализация для всех частот
- Корректная работа с различными частотами

#### test_audio_decoder_channels
**Назначение:** Проверка поддержки различных конфигураций каналов.

**Тестируемые конфигурации:**
- 1 канал (Mono)
- 2 канала (Stereo)
- 5 каналов (5.1)
- 6 каналов (6.1)

**Проверяет:**
- Успешная инициализация для всех конфигураций
- Корректная работа с различным количеством каналов

## 📝 Тестовые данные

### AAC Frame
Минимальный валидный AAC frame для тестирования:
```cpp
static const uint8_t test_aac_frame[] = {
    0xFF, 0xF1, 0x50, 0x80, 0x00, 0x1F, 0xFC, ...
};
```

### PCMU Frame
8 байт данных для 1 мс аудио при 8kHz:
```cpp
static const uint8_t test_pcmu_frame[] = {
    0x7E, 0x7F, 0x80, 0x81, 0x82, 0x83, 0x84, 0x85
};
```

### PCMA Frame
8 байт данных для 1 мс аудио при 8kHz:
```cpp
static const uint8_t test_pcma_frame[] = {
    0xD5, 0xD6, 0xD7, 0xD8, 0xD9, 0xDA, 0xDB, 0xDC
};
```

## 🐛 Примечания

1. **Минимальные тестовые данные:** Используются упрощенные тестовые данные. Для более полного тестирования рекомендуется использовать реальные аудио кадры из RTSP потоков.

2. **FFmpeg зависимость:** Тесты требуют FFmpeg для работы. Если FFmpeg не включен, тесты вернут соответствующие сообщения.

3. **AAC декодирование:** Минимальные тестовые данные могут не декодироваться полностью, но функция должна вызываться без ошибок.
