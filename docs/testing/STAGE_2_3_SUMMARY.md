## 📝 Примечания

1. **Тестовые камеры**: Для тестирования можно использовать:
   - Реальные RTSP камеры
   - Эмуляторы RTSP (MediaMTX, FFmpeg RTSP сервер)
   - Тестовые потоки

2. **Конфигурация**: Упрощенный парсер конфигурации включен в код. Для полной поддержки JSON рекомендуется использовать библиотеку (например, nlohmann/json).

3. **Длительное тестирование**: Для тестирования стабильности увеличьте `decoding_test_duration_seconds` в конфигурации.
