## ⚠️ Требуется для завершения

### Для полного завершения Этапа 2.1.2:

1. **Открыть Developer Command Prompt для Visual Studio**
2. **Выполнить сборку:**
   ```powershell
   cd native\video-processing
   mkdir build\windows-x64
   cd build\windows-x64

   cmake ..\.. `
       -G "Visual Studio 17 2022" `
       -A x64 `
       -DCMAKE_BUILD_TYPE=Release `
       -DENABLE_FFMPEG=ON `
       -DENABLE_OPENCV=OFF `
       -DFFMPEG_DIR=C:\ffmpeg

   cmake --build . --config Release
   ```

3. **Проверить результат:**
   - Библиотека `video_processing.dll` создана
   - FFmpeg библиотеки линкуются
   - Символы экспортируются
