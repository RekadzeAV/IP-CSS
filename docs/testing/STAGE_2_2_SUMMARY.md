## ⚠️ Требуется для запуска

### Предварительные условия:
1. ✅ Библиотека `video_processing` собрана с FFmpeg
2. ✅ FFmpeg development files доступны
3. ⚠️ Компилятор C++ (Visual Studio или MinGW)

### Сборка тестов:

```bash
cd native/video-processing/test
mkdir build && cd build

cmake .. \
    -DCMAKE_BUILD_TYPE=Release \
    -DENABLE_FFMPEG=ON

cmake --build . --config Release
```

### Запуск тестов:

```bash
./video_processing_tests
# или
ctest
```

## 📝 Примечания

1. **Тестовые данные**: Минимальные тестовые данные включены в код. Для более полного тестирования рекомендуется использовать реальные NAL units из RTSP потоков.

2. **FFmpeg зависимость**: Тесты требуют FFmpeg для работы. Если FFmpeg не включен, тесты вернут соответствующие сообщения.

3. **Простой фреймворк**: Используется простой тестовый фреймворк без внешних зависимостей. Можно заменить на Google Test для более продвинутых возможностей.
