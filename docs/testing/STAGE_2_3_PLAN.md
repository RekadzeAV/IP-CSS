# Этап 2.3: Интеграционные тесты - План

**Дата:** 27 January 2026
**Приоритет:** 🔴 Критично для MVP
**Оценка времени:** 3-4 дня

---

## 🎯 Цели

Протестировать FFmpeg декодирование в RTSP клиенте на реальных камерах с минимальным набором тестов.

---

## 📋 Задачи

### 2.3.1: Подготовка тестовых камер (1 день)

**Задачи:**
1. Настроить доступ к тестовым RTSP камерам
   - Реальные камеры (если доступны)
   - Или эмуляторы RTSP (MediaMTX, FFmpeg RTSP сервер)

2. Документировать параметры камер:
   - RTSP URL
   - Учетные данные (если требуются)
   - Кодек (H.264/H.265)
   - Разрешение
   - FPS
   - Профиль (Baseline/Main/High для H.264)

3. Создать конфигурационный файл для тестов:
   ```json
   {
     "cameras": [
       {
         "name": "Test Camera 1",
         "url": "rtsp://192.168.1.100:554/stream",
         "username": "admin",
         "password": "password",
         "codec": "H264",
         "resolution": "1920x1080",
         "fps": 25
       }
     ]
   }
   ```

### 2.3.2: Базовые интеграционные тесты (1 день)

**Тесты:**
1. **Подключение к камере**
   - Успешное подключение
   - Обработка ошибок подключения
   - Таймауты

2. **Получение видеокадров**
   - Получение первого кадра
   - Получение нескольких кадров подряд
   - Проверка метаданных (разрешение, кодек)

3. **Декодирование кадров**
   - Успешное декодирование
   - Проверка формата выходных данных (RGB/YUV)
   - Проверка разрешения декодированных кадров

### 2.3.3: Тестирование различных кодеков и профилей (1 день)

**Тесты:**
1. **H.264 Baseline Profile**
   - 640x480 @ 15 FPS
   - 1280x720 @ 25 FPS

2. **H.264 Main Profile**
   - 1280x720 @ 25 FPS
   - 1920x1080 @ 25 FPS

3. **H.264 High Profile** (если доступно)
   - 1920x1080 @ 30 FPS

4. **H.265/HEVC** (если доступно)
   - 1920x1080 @ 25 FPS

### 2.3.4: Проверка производительности и стабильности (1 день)

**Метрики:**
1. **Производительность:**
   - FPS декодирования
   - Задержка декодирования (latency)
   - Использование CPU
   - Использование памяти

2. **Стабильность:**
   - Длительное воспроизведение (30+ минут)
   - Проверка на утечки памяти
   - Обработка сетевых ошибок
   - Переподключение при разрыве соединения
