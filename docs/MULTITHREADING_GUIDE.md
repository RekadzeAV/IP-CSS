# Руководство по многопоточности в VideoDecoder

## Обзор

VideoDecoder поддерживает многопоточное декодирование для улучшения производительности на многоядерных системах.

## Как это работает

### Программное декодирование
- Использует несколько потоков для параллельной обработки кадров
- Количество потоков = min(количество CPU ядер, 4)
- Тип многопоточности: `AV_THREAD_FRAME | AV_THREAD_SLICE`

### Аппаратное декодирование
- Обычно не требует многопоточности (GPU обрабатывает параллельно)
- Устанавливается `thread_count = 1` для стабильности

## Настройка

Многопоточность включена по умолчанию. Для отключения:

```kotlin
// В VideoDecoderImpl (внутренний класс)
// Установите enableMultithreading = false
```

## Производительность

### Ожидаемые улучшения

- **Multi-core systems**: Улучшение на 30-50% для 4+ ядер
- **High resolution**: Больше выигрыш для 1080p и выше
- **CPU-bound scenarios**: Значительное улучшение

### Зависит от:
- Количества CPU ядер
- Разрешения видео
- Типа кодека
- Нагрузки системы

## Ограничения

1. **Аппаратное декодирование**: Многопоточность обычно не нужна
2. **Низкие разрешения**: Может быть overhead
3. **Memory**: Больше потоков = больше памяти

## Мониторинг

Метрики производительности включают информацию о многопоточности:
- Среднее время декодирования
- FPS
- Использование CPU

## Статус реализации

- ✅ Многопоточность для программных декодеров
- ✅ Автоматическое определение количества потоков
- ✅ Оптимизация для аппаратных декодеров
- ⏳ Требуется тестирование на различных системах
