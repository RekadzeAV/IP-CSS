## 🔗 Интеграция с IP-CSS

### План Интеграции:

#### 1. Проверка Доступности:

```bash
# Проверка ping
ping 192.168.10.250

# Проверка RTSP порта
telnet 192.168.10.250 554

# Проверка веб-интерфейса
curl http://192.168.10.250
```

#### 2. Добавление Камер в IP-CSS:

```bash
# Через API
curl -X POST http://localhost:8080/api/v1/cameras \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "NVR Camera 1",
    "url": "rtsp://Kassian:123456@wSx@192.168.10.250:554/cam1",
    "username": "Kassian",
    "password": "123456@wSx"
  }'
```

#### 3. Настройка ONVIF Подписки:

```bash
# Проверка ONVIF доступности
curl http://192.168.10.250:8080/onvif/device_service
```

### Возможности Интеграции:

## 🎯 Рекомендации

### 1. Проверка ONVIF:

- [ ] Убедиться, что ONVIF включён в настройках NVR

## 🛠️ Устранение Проблем

### Проблема: NVR не отвечает

**Решение:**
1. Проверить подключение к сети: `ping 192.168.10.250`
2. Проверить настройки IP
3. Перезагрузить устройство

### Проблема: RTSP потоки недоступны

**Решение:**
1. Проверить учётные данные
2. Проверить порт 554 открыт
3. Проверить формат RTSP URL

### Проблема: ONVIF события не приходят

**Решение:**
1. Включить ONVIF в настройках NVR
2. Проверить порт ONVIF
3. Переподписаться на события в IP-CSS
