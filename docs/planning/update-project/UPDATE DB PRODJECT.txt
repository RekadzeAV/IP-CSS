Заголовок: Миграция серверного хранилища с in-memory на PostgreSQL + TimescaleDB
Описание
В настоящее время серверные репозитории (CameraRepositoryImpl, EventRepositoryImpl, RecordingRepositoryImpl, UserRepositoryImpl, SettingsRepositoryImpl, NotificationRepositoryImpl) используют in-memory хранение. Это неприемлемо для production-среды, так как данные теряются при перезапуске, отсутствует масштабирование и нет поддержки временных рядов.

Необходимо внедрить постоянную СУБД с поддержкой:

ACID-транзакций

Эффективной работы с временными рядами (события, записи)

Связей между сущностями (камеры → записи → события)

Ролевой модели для пользователей

Возможности горизонтального масштабирования в будущем

Выбранное решение: PostgreSQL 14+ + расширение TimescaleDB (для оптимизации временных рядов) + Redis (для кэширования и сессий).
