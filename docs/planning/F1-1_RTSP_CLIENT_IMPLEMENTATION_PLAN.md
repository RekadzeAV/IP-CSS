## 🚀 Начало реализации

### Шаг 1: Проверка FFmpeg в системе

```powershell
# Проверка наличия FFmpeg
ffmpeg -version
ffprobe -version

# Если не установлено - установить
# Windows: choco install ffmpeg
# Linux: sudo apt install ffmpeg
# macOS: brew install ffmpeg
```

### Шаг 2: Сборка нативной библиотеки

```powershell
# Перейти в директорию проекта
cd native/video-processing

# Создать build директорию
cmake -B build/windows/x64 -G "Visual Studio 17 2022" -A x64 -DCMAKE_BUILD_TYPE=Release

# Собрать
cmake --build build/windows/x64 --config Release
```

### Шаг 3: Проверка загрузки библиотеки

```kotlin
// Тест NativeRtspClientFfmpegDecodingTest
@Test
fun testNativeLibraryLoaded() {
    val client = NativeRtspClient()
    val handle = client.create()
    assertTrue(handle != 0L, "Native library should be loaded")
}
```
