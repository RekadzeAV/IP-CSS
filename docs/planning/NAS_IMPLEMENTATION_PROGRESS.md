## ✅ Выполнено в этой сессии

### 1. NasPlatformDetector - Определение платформы и путей

**Создано:**
- ✅ Интерфейс `NasPlatformDetector` в `shared/src/commonMain/`
- ✅ JVM реализация с полной логикой определения платформ
- ✅ Реализации для Android, iOS, Desktop (заглушки)

**Функциональность:**
- Автоматическое определение платформы (Synology, QNAP, Asustor, TrueNAS)
- Получение системных путей для каждой платформы
- Fallback на пути по умолчанию

**Файлы:**
- `shared/src/commonMain/kotlin/.../NasPlatformDetector.kt`
- `shared/src/jvmMain/kotlin/.../NasPlatformDetectorImpl.kt`
- `shared/src/androidMain/kotlin/.../NasPlatformDetectorImpl.kt`
- `shared/src/iosMain/kotlin/.../NasPlatformDetectorImpl.kt`
- `shared/src/desktopMain/kotlin/.../NasPlatformDetectorImpl.kt`

### 2. Скрипт определения путей

**Создано:**
- ✅ `detect-nas-paths.sh` - универсальный скрипт для определения системных путей

**Функциональность:**
- Определение платформы через системные файлы
- Получение путей для данных, записей, логов, конфигурации
- Поддержка всех основных NAS платформ

**Расположение:**
- `platforms/nas-x86_64/packages/synology/package/bin/detect-nas-paths.sh`
- `platforms/nas-x86_64/packages/qnap/scripts/detect-nas-paths.sh`
- `platforms/nas-x86_64/packages/asustor/package/bin/detect-nas-paths.sh`
