## 🔧 Технические детали

### Зависимости

**Для Задачи 1 (Desktop видеоплеер):**
- JavaCV 1.5.9+ (уже добавлено)
- FFmpeg 6.0+ (для нативной библиотеки)
- CMake 3.20+ (для сборки нативной библиотеки)
- Kotlin/Native компилятор

**Для Задачи 2 (Тестирование FFmpeg):**
- FFmpeg 6.0+ (установлен в системе)
- Тестовые RTSP камеры (реальные или эмуляторы)
- CMake 3.20+ (для сборки с FFmpeg)
- C++ компилятор (GCC/Clang/MSVC)

### Риски и митигация

**Риск 1: FFmpeg не найден при сборке**
- **Митигация:** Документировать установку FFmpeg, использовать переменные окружения

**Риск 2: Проблемы с производительностью декодирования**
- **Митигация:** Оптимизировать выделение памяти, использовать аппаратное ускорение (если доступно)

**Риск 3: Отсутствие тестовых камер**
- **Митигация:** Использовать эмуляторы RTSP (например, MediaMTX), создать тестовые потоки

**Риск 4: Проблемы с кроссплатформенностью**
- **Митигация:** Тестировать на всех целевых платформах, использовать условную компиляцию
