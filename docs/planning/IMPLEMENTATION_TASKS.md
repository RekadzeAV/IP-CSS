## 🎯 15 приоритетных задач для реализации

### 🔴 Критический приоритет (MVP блокеры)

#### 1. Интеграция WebSocket клиента в веб-интерфейс
**Статус:** ⚠️ Сервер готов, клиент требует интеграции
**Файлы:** `server/web/src/services/websocketService.ts` (создать), `server/web/src/hooks/useWebSocket.ts` (создать)
**Задачи:**
- Создать WebSocket сервис для подключения к `/api/v1/ws`
- Реализовать React hook `useWebSocket` для подписки на каналы
- Интегрировать в компоненты для real-time обновлений (камеры, события, записи)
- Обработка переподключений и ошибок
- Подписка на каналы: `cameras`, `events`, `recordings`, `notifications`

**Оценка:** 3-5 дней

---

#### 2. Завершение ONVIF WS-Discovery для обнаружения камер
**Статус:** ⚠️ Частично реализовано (~40%)
**Файлы:** `core/network/src/commonMain/kotlin/com/company/ipcamera/core/network/OnvifClient.kt`
**Задачи:**
- Реализовать UDP multicast отправку SOAP Probe запросов на `239.255.255.250:3702`
- Обработка ProbeMatches ответов от камер
- Парсинг XML ответов (улучшить текущий упрощенный парсинг)
- Фильтрация устройств по типам (NetworkVideoTransmitter)
- Интеграция с `CameraRepositoryImpl.discoverCameras()`

**Оценка:** 1-2 недели

---

#### 3. Реализация видеоплеера с поддержкой RTSP через медиа-сервер
**Статус:** ⚠️ Компонент есть, требует интеграции
**Файлы:** `server/web/src/components/VideoPlayer/VideoPlayer.tsx`, создать медиа-сервер
**Задачи:**
- Создать медиа-сервер (Node.js/Go) для трансляции RTSP → HLS/WebRTC
- Интеграция с существующим VideoPlayer компонентом
- Поддержка HLS стриминга (через HLS.js)
- Опционально: WebRTC для низкой задержки
- Управление качеством потока
- Обработка ошибок подключения

**Оценка:** 2-3 недели

---

#### 4. Безопасное хранение JWT токенов в веб-интерфейсе
**Статус:** ❌ Токены в localStorage (уязвимо для XSS)
**Файлы:** `server/web/src/utils/api.ts`, `server/web/src/services/authService.ts`
**Задачи:**
- Мигрировать с localStorage на httpOnly cookies
- Обновить серверную часть для установки cookies при логине
- Обновить Axios interceptors для работы с cookies
- Удалить ручное управление токенами из localStorage

**Оценка:** 2-3 дня

---

#### 5. SSL/TLS Certificate Pinning для всех клиентов
**Статус:** ❌ Не реализовано
**Файлы:** `core/network/src/*/kotlin/.../ApiClient.*.kt`
**Задачи:**
- Реализовать certificate pinning для Android (Network Security Config)
- Реализовать certificate pinning для iOS (URLSession)
- Реализовать certificate pinning для веб-интерфейса (если возможно)

**Оценка:** 1-2 недели
