## ⚠️ Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Камеры недоступны | Средняя | Высокое | Использовать RTSP тестовые серверы (ffserver, ffprobe) |
| Разные реализации RTSP | Высокая | Среднее | Тестировать с различными производителями |
| Проблемы с сетью | Низкая | Высокое | Проверить firewall, port forwarding |
| Устаревшие прошивки | Средняя | Среднее | Обновить прошивки камер перед тестированием |

## 🔧 Утилиты для диагностики

### Проверка RTSP потока через ffprobe

```bash
# Проверка SDP
ffprobe -i rtsp://user:pass@192.168.1.100:554/stream

# Проверка аудио
ffprobe -i rtsp://user:pass@192.168.1.100:554/stream -show_streams

# Проверка в реальном времени
ffplay rtsp://user:pass@192.168.1.100:554/stream
```

### Мониторинг сети

```powershell
# Мониторинг трафика
Test-NetConnection -ComputerName 192.168.1.100 -Port 554 -InformationLevel Detailed

# Ping с статистикой
ping -n 100 192.168.1.100
```
