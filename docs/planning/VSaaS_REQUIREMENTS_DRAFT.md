# Черновик требований: VSaaS и размещение аналитики

**Статус:** черновик для ТЗ и договоров; облачная реализация не входит в текущий MVP кода.

## Модели размещения

1. **ON_PREM** — вся обработка и хранение на площадке заказчика.
2. **CUSTOMER_SERVER** — выделенный сервер заказчика (ЦОД), без публичного мультитенантного SaaS.
3. **VSAAS** — провайдер размещает инстансы/шарды; требуется отдельная продуктовая и юридическая проработка.

## Минимальные требования к VSaaS (когда продукт дойдёт до реализации)

- Шифрование канала (TLS 1.2+), опционально end-to-end для видео по согласованию.
- Изоляция данных арендаторов (tenant ID, политики RBAC).
- Аудит доступа к архиву и экспортам.
- Согласование юрисдикции хранения и сроков ретенции.

## Связь с кодом

В доменной модели зафиксировано поле `AnalyticsSettings.executionLocation` (`ON_PREM` | `CUSTOMER_SERVER` | `VSAAS`) — см. `shared/.../AnalyticsExecutionLocation.kt`.
