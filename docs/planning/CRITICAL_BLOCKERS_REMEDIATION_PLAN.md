## 📋 Критические блокеры

### 1. Расширение RBAC в EventRoutes/RecordingRoutes ✅ ЗАВЕРШЕНО
**Приоритет:** 🔴 Высокий
**Оценка времени:** 1-2 дня
**Статус:** ✅ Завершено

**Проблема:**
- RBAC уже реализован в EventRoutes и RecordingRoutes через `requireRole()`
- Требуется проверка всех endpoints на правильность применения RBAC
- Возможно, требуется добавление более гранулярных проверок разрешений

**Задачи:**
- [x] Проверить все endpoints в EventRoutes на наличие RBAC ✅
- [x] Проверить все endpoints в RecordingRoutes на наличие RBAC ✅
- [x] Проверить все endpoints в CameraRoutes на наличие RBAC ✅
- [x] Добавить requireRole для GET /cameras ✅
- [x] Добавить тесты для проверки RBAC ✅
- [ ] Обновить документацию

**Текущее состояние:**
- ✅ EventRoutes: все endpoints защищены через `requireRole()`:
  - GET /events - VIEWER
  - GET /events/{id} - VIEWER
  - DELETE /events/{id} - OPERATOR
  - POST /events/{id}/acknowledge - OPERATOR
  - POST /events/acknowledge - OPERATOR
  - GET /events/statistics - VIEWER
- ✅ RecordingRoutes: все endpoints защищены через `requireRole()`:
  - GET /recordings - VIEWER
  - GET /recordings/{id} - VIEWER
  - DELETE /recordings/{id} - OPERATOR
  - GET /recordings/{id}/download - VIEWER
  - POST /recordings/{id}/export - OPERATOR
  - POST /recordings/start - OPERATOR
  - POST /recordings/stop/{cameraId} - OPERATOR
  - POST /recordings/pause/{cameraId} - OPERATOR
  - POST /recordings/resume/{cameraId} - OPERATOR
- ✅ CameraRoutes: все endpoints защищены через `requireRole()`:
  - GET /cameras - требует аутентификации (но не проверяет роль - нужно добавить)
  - POST /cameras - OPERATOR
  - Остальные endpoints также защищены
- ⚠️ Требуется: добавление тестов и проверка GET /cameras (добавить requireRole)
