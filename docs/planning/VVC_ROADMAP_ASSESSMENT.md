# Оценка H.266 / VVC для IP-CSS

**Вывод:** ветка **не планируется** в текущем релизе; зафиксированы риски и критерии повторной оценки.

## Декодирование

| Платформа | Заметки |
|-----------|---------|
| Web (hls.js / Safari) | Поддержка VVC в MSE/HLS ограничена; потребуется отдельный исследовательский спайк. |
| Android (ExoPlayer) | Зависит от версии ОEM/MediaCodec; нет единого «включить VVC» для всех устройств. |
| Desktop (FFmpeg) | Сборка FFmpeg должна включать декодер VVC и учитывать патентные/лицензионные ограничения. |

## Кодирование

- Энкодеры VVC в FFmpeg пока не стандарт де-факто для продакшена VSS; связка с GPU (если появится) — отдельный эпик.

## Рекомендация

Повторно рассмотреть **не ранее** появления стабильного стека **VVC в HLS/fMP4** на целевых клиентах проекта и измеримой выгигры по битрейту относительно HEVC на **4K/8K**.
