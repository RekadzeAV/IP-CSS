## Следующие шаги

### Для полной функциональности:

1. **Установить FFmpeg с dev-пакетами:**
   - См. `FFMPEG_WINDOWS_SETUP.md` для инструкций
   - Скачать полную версию FFmpeg с заголовочными файлами и библиотеками

2. **Пересобрать библиотеку с FFmpeg:**
   ```powershell
   cd native\video-processing\build
   Remove-Item -Recurse -Force *
   cmake .. -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DENABLE_FFMPEG=ON
   cmake --build . --config Release
   ```

### Для тестирования:

1. **Проверить интеграцию с Kotlin:**
   ```bash
   ./gradlew :core:network:build
   ```

2. **Протестировать RTSP клиент:**
   - Создать unit-тесты
   - Протестировать с тестовым RTSP сервером
