## 📝 Технические детали

### Валидация URL камер

**Улучшения:**
- Проверка порта для RTSP URL (1-65535)
- Проверка наличия пути в RTSP URL
- Более детальные сообщения об ошибках

**Пример валидации:**
```kotlin
// Валидные RTSP URL:
rtsp://192.168.1.100:554/stream1
rtsp://camera.example.com/h264

// Невалидные RTSP URL:
rtsp://192.168.1.100:554/  // Путь пустой
rtsp://192.168.1.100:70000/stream1  // Порт вне диапазона
```

### Валидация событий

**Ограничения:**
- Минимум 1 событие для подтверждения
- Максимум 100 событий за раз
- Каждый ID должен быть непустой строкой до 100 символов

### Валидация настроек

**Ограничения:**
- Минимум 1 настройка для обновления
- Ключ настройки: непустой, максимум 100 символов
- Значение настройки: максимум 10000 символов
