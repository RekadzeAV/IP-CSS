# Версионирование документации проекта IP-CSS

**Версия системы версионирования:** 1.0
**Дата создания:** 26 January 2026
**Последнее обновление:** 26 January 2026

---

## 📋 Обзор

Этот документ описывает процесс версионирования документации проекта IP-CSS. При оптимизации или значительных изменениях документации старая версия сохраняется в архиве, а версия документа увеличивается.

---

## 🎯 Цели версионирования

1. **Сохранение истории** - возможность вернуться к предыдущим версиям
2. **Отслеживание изменений** - понимание эволюции документации
3. **Восстановление** - возможность восстановить удаленную информацию
4. **Аудит** - отслеживание того, что и когда было изменено

---

## 📁 Структура архива

```
docs/archive/
├── YYYY-MM-DD/          # Папка на дату внесения изменений
│   ├── DOCUMENT_NAME.md # Старая версия документа
│   └── ...
├── README.md            # Описание архива
└── .gitkeep             # Для сохранения каталога в Git
```

**Формат даты:** `YYYY-MM-DD` (например, `2026-01-27`)

---

## 🔄 Процесс версионирования

### Шаг 1: Подготовка

Перед изменением документа:

1. Определите текущую версию документа (проверьте метаданные)
2. Определите тип изменения:
   - **Мажорная версия** (2.0 → 3.0): значительные изменения структуры
   - **Минорная версия** (2.0 → 2.1): дополнения или улучшения
   - **Патч-версия** (2.0 → 2.0.1): исправления ошибок

### Шаг 2: Архивирование

**Автоматически (рекомендуется):**

```bash
# Windows PowerShell
.\scripts\archive-documentation.ps1 -Document "docs/ARCHITECTURE.md" -Version "2.0" -NewVersion "3.0"

# Linux/macOS
./scripts/archive-documentation.sh docs/ARCHITECTURE.md 2.0 3.0
```

**Вручную:**

1. Создайте папку `docs/archive/YYYY-MM-DD/` (если не существует)
2. Скопируйте документ в архив:
   ```bash
   cp docs/ARCHITECTURE.md docs/archive/2026-01-27/ARCHITECTURE.md
   ```

### Шаг 3: Обновление документа

1. Внесите изменения в документ
2. Обновите метаданные в начале документа:

```markdown
# Название документа

**Версия документации:** 3.0
**Дата последнего обновления:** 26 January 2026
**Предыдущая версия:** 2.0 (архивирована: 27 января 2025)
```

3. Обновите дату последнего обновления

### Шаг 4: Обновление индексов

1. Обновите `DOCUMENTATION_INDEX.md` (если изменилась структура)
2. Обновите `docs/README.md` (если изменилась навигация)
3. Обновите `docs/archive/README.md` (добавьте запись о новой версии)

## 📝 Формат метаданных

Каждый документ должен содержать метаданные в начале:

```markdown
# Название документа

**Версия документации:** X.Y[.Z]
**Дата последнего обновления:** 26 January 2026
**Дата создания:** 26 January 2026
**Предыдущая версия:** X.Y (архивирована: DD MMMM YYYY) [опционально]

> **📚 Полный индекс документации:** [DOCUMENTATION_INDEX.md](../DOCUMENTATION_INDEX.md)
> **📦 Архивная документация:** Старые версии сохранены в `docs/archive/`
```

### Примеры

**Мажорная версия:**
```markdown
**Версия документации:** 3.0
**Дата последнего обновления:** 26 January 2026
**Предыдущая версия:** 2.0 (архивирована: 27 января 2025)
```

**Минорная версия:**
```markdown
**Версия документации:** 2.1
**Дата последнего обновления:** 26 January 2026
**Предыдущая версия:** 2.0 (архивирована: 15 февраля 2025)
```

## 🛠️ Автоматизация

### Скрипты

#### Windows PowerShell: `scripts/archive-documentation.ps1`

```powershell
# Использование
.\scripts\archive-documentation.ps1 `
    -Document "docs/ARCHITECTURE.md" `
    -Version "2.0" `
    -NewVersion "3.0" `
    -Date "2026-01-27"
```

#### Linux/macOS: `scripts/archive-documentation.sh`

```bash
# Использование
./scripts/archive-documentation.sh \
    docs/ARCHITECTURE.md \
    2.0 \
    3.0 \
    2026-01-27
```

### Что делают скрипты

1. ✅ Проверяют существование документа
2. ✅ Создают папку архива на дату (если не существует)
3. ✅ Копируют документ в архив
4. ✅ Обновляют версию в документе
5. ✅ Обновляют дату последнего обновления
6. ✅ Добавляют информацию о предыдущей версии

## 📊 Типы изменений и версионирование

| Тип изменения | Пример | Версионирование |
|---------------|--------|-----------------|
| **Значительная реорганизация** | Объединение 10 файлов в 3 | Мажорная (2.0 → 3.0) |
| **Изменение структуры** | Перемещение разделов | Мажорная (2.0 → 3.0) |
| **Добавление разделов** | Новые главы | Минорная (2.0 → 2.1) |
| **Обновление информации** | Актуализация данных | Минорная (2.0 → 2.1) |
| **Исправление ошибок** | Правка опечаток | Патч (2.0 → 2.0.1) |
| **Обновление ссылок** | Исправление битых ссылок | Патч (2.0 → 2.0.1) |

3. Найдите документ по имени

3. Найдите документ в соответствующей папке
