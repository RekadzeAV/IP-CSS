## 🔧 Технические детали

### FFmpeg интеграция

**Поддерживаемые форматы:**
- MP4 (libx264 + AAC, faststart для веб)
- MKV (libx264 + AAC)
- AVI (libx264 + libmp3lame)
- MOV (libx264 + AAC, faststart)
- FLV (libx264 + libmp3lame)

**Настройки качества:**
- LOW: CRF 28, 500k bitrate
- MEDIUM: CRF 23, 2000k bitrate
- HIGH: CRF 20, 4000k bitrate
- ULTRA: CRF 18, 8000k bitrate

### SQLDelight миграция

**Используемые запросы:**
- `selectAllRecordings()` - все записи
- `selectRecordingById()` - по ID
- `selectRecordingsByCameraId()` - по камере
- `selectRecordingsByDateRange()` - по диапазону времени
- `insertRecording()` - добавление
- `updateRecording()` - обновление
- `deleteRecording()` - удаление

**Индексы:**
- `recording_camera_id_index`
- `recording_start_time_index`
- `recording_status_index`
- `recording_created_at_index`

### Управление хранилищем

**Квоты:**
- Настраиваемый максимальный размер хранилища
- Автоматический расчет используемого места
- Проверка перед записью

**Мониторинг:**
- Процент использования диска
- Порог предупреждения (по умолчанию 80%)
- Детальная статистика (total, used, available)

## ⚠️ Известные ограничения

### FFmpeg
- Требует установки FFmpeg в системе
- Fallback на старый метод, если недоступен
- Процессы FFmpeg могут потреблять много ресурсов

### SQLDelight
- Использует локальную SQLite базу данных
- Для распределенных систем требуется PostgreSQL
- Миграции данных из in-memory не реализованы

### Управление хранилищем
- Квоты не настраиваются через конфигурацию (требуется код)
- Нет автоматического удаления при превышении квоты
- Расчет размера записи приблизительный
