## Обзор проекта

### Назначение

Desktop приложение IP-CSS - это нативное кроссплатформенное приложение для управления системой видеонаблюдения, работающее на Windows, Linux и macOS. Приложение предоставляет полнофункциональный интерфейс для управления камерами, просмотра видео в реальном времени, работы с записями и событиями.

### Поддерживаемые платформы

- **Windows 10/11** (x64)
- **Linux** (Ubuntu, Debian, Fedora, Arch и др.) (x64, ARM64)
- **macOS** (Intel x64, Apple Silicon ARM64)

### Основной функционал

1. **Управление камерами** - CRUD операции, обнаружение, тестирование
2. **Просмотр видео** - RTSP потоки, многокамерный просмотр, PTZ управление
3. **Управление записями** - просмотр, воспроизведение, экспорт
4. **События и уведомления** - просмотр событий, фильтрация, системные уведомления
5. **Настройки** - конфигурация приложения, пользователи, лицензирование

## Архитектура и технологический стек

### Архитектурный паттерн

**MVI (Model-View-Intent)** с элементами **MVVM**:

```
┌─────────────────────────────────────────┐
│         UI Layer (Compose Desktop)      │
│  Screens → Components → Navigation      │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────┼──────────────────────┐
│      State Layer (ViewModels)           │
│  ViewModel → State → Intent/Action      │
└──────────────────┼──────────────────────┘
                   │
┌──────────────────┼──────────────────────┐
│  Business Logic (Shared KMP)            │
│  Use Cases → Domain Models              │
└──────────────────┼──────────────────────┘
                   │
┌──────────────────┼──────────────────────┐
│      Data Layer (Shared KMP)            │
│  Repositories → API/DB/FileSystem       │
└─────────────────────────────────────────┘
```

### Технологический стек

| Компонент | Технология | Версия |
|-----------|-----------|--------|
| UI Framework | Compose Desktop | 1.7.0+ |
| Dependency Injection | Koin | 3.6.0 |
| Навигация | Compose Navigation (кастомная) | - |
| Состояние | Kotlinx Coroutines Flow | - |
| Сетевые запросы | Ktor Client | (из :core:network) |
| Локальная БД | SQLDelight | 2.0.3 |
| Логирование | Kotlin Logging | 3.0.5 |
| Видео | Нативные библиотеки (C++) | (из native/) |

   - **Вероятность:** Высокая
   - **Влияние:** Высокое (влияет на UX)

     - Использовать hardware acceleration
     - Оптимизировать рендеринг
     - Ограничить количество одновременных потоков

### B. Примеры кода

#### Пример: RtspClientWrapper (expect/actual)

```kotlin
// commonMain
expect class RtspClientWrapper {
    fun connect(url: String, username: String?, password: String?): Boolean
    fun disconnect()
    fun getFrame(): ByteArray?
    fun isConnected(): Boolean
}

// desktopMain (JVM)
actual class RtspClientWrapper {
    private var nativeHandle: Long = 0

    actual fun connect(url: String, username: String?, password: String?): Boolean {
        // JNI вызов к нативной библиотеке
        return nativeConnect(nativeHandle, url, username, password)
    }

    actual fun disconnect() {
        nativeDisconnect(nativeHandle)
    }

    actual fun getFrame(): ByteArray? {
        return nativeGetFrame(nativeHandle)
    }

    actual fun isConnected(): Boolean {
        return nativeIsConnected(nativeHandle)
    }

    private external fun nativeConnect(handle: Long, url: String, username: String?, password: String?): Boolean
    private external fun nativeDisconnect(handle: Long)
    private external fun nativeGetFrame(handle: Long): ByteArray?
    private external fun nativeIsConnected(handle: Long): Boolean
}
```
