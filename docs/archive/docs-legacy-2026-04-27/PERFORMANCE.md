## Оптимизация записи видео

### Настройки кодека

**H.264:**
```yaml
video:
  codec: h264
  preset: medium  # fast, medium, slow
  tune: zerolatency
  bitrate: 2000  # kbps
  crf: 23  # Constant Rate Factor (18-28)
```

**H.265 (HEVC):**
```yaml
video:
  codec: h265
  preset: medium
  bitrate: 1500  # Меньше чем H.264 при том же качестве
```

### Аппаратное ускорение

**NVIDIA GPU:**
```yaml
video:
  hardwareAcceleration: true
  encoder: h264_nvenc  # или hevc_nvenc
```

**Intel Quick Sync:**
```yaml
video:
  hardwareAcceleration: true
  encoder: h264_qsv
```

### Оптимизация качества

- Используйте переменный битрейт (VBR)
- Настройте GOP (Group of Pictures) размер
- Используйте профили кодека (baseline, main, high)

## Оптимизация просмотра

### Потоковая передача

**HLS (HTTP Live Streaming):**
- Используйте адаптивный битрейт
- Настройте размер сегментов (6-10 секунд)
- Используйте CDN для раздачи

**WebRTC:**
- Используйте для низкой задержки
- Настройте качество в зависимости от пропускной способности

### Кэширование

- Кэшируйте статические ресурсы
- Используйте HTTP кэширование
- Кэшируйте метаданные записей

## Оптимизация AI-аналитики

### Модели

- Используйте легковесные модели (YOLOv8n вместо YOLOv8x)
- Квантуйте модели (INT8)
- Используйте специализированные модели для конкретных задач

### Обработка

- Пропускайте кадры (обрабатывайте каждый N-й кадр)
- Уменьшайте разрешение входного изображения
- Используйте GPU ускорение

### Параллелизация

- Обрабатывайте несколько потоков параллельно
- Используйте пул потоков для обработки

## Оптимизация базы данных

### Индексы

```sql
-- Создайте индексы для часто используемых запросов
CREATE INDEX idx_camera_id ON recordings(camera_id);
CREATE INDEX idx_timestamp ON recordings(timestamp);
CREATE INDEX idx_event_type ON events(event_type);
```

### Запросы

- Используйте пагинацию
- Избегайте N+1 запросов
- Используйте JOIN вместо множественных запросов

### Пулы соединений

```yaml
database:
  poolSize: 20
  maxLifetime: 1800000
  connectionTimeout: 30000
```

## Оптимизация сети

### Сжатие

- Используйте gzip/brotli для HTTP ответов
- Сжимайте API ответы

### Keep-Alive

- Используйте HTTP Keep-Alive
- Настройте таймауты соединений

## Рекомендации по оборудованию

### Минимальные требования

- **CPU:** 4 ядра, 2.0 GHz
- **RAM:** 4 GB
- **Storage:** SSD рекомендуется
- **Network:** 100 Mbps

### Рекомендуемые требования

- **CPU:** 8+ ядер, 3.0+ GHz
- **RAM:** 8+ GB
- **Storage:** SSD + HDD массив
- **Network:** 1 Gbps
- **GPU:** NVIDIA GTX 1060+ (для AI-аналитики)

### Для высокой производительности

- **CPU:** 16+ ядер, 3.5+ GHz
- **RAM:** 16+ GB
- **Storage:** NVMe SSD
- **Network:** 10 Gbps
- **GPU:** NVIDIA RTX 3060+ или специализированные NPU
