## Введение

Данное руководство предназначено для конечных пользователей системы видеонаблюдения IP-CSS, которые используют систему для просмотра камер, записей и событий.

### Роль пользователя (VIEWER)

Пользователь с ролью VIEWER имеет доступ к следующим функциям:
- Просмотр камер в реальном времени
- Просмотр записей
- Просмотр событий
- Экспорт записей (если разрешено)
- Настройка личного профиля

**Ограничения:**
- Не может управлять камерами
- Не может управлять событиями
- Не может изменять системные настройки
- Не может управлять другими пользователями

- **Версия ОС:** iOS 14.0+
- **Установка:** App Store или TestFlight
- **Особенности:** Push-уведомления, интеграция с iOS

- **Архитектура:** x86_64
- **Версия ОС:** Windows 10/11
- **Установка:** Microsoft Store или установщик
- **Особенности:** Нативный интерфейс, системные уведомления

## Начало работы

### Первый вход

#### Веб-интерфейс

1. Откройте браузер
2. Перейдите по адресу, предоставленному администратором
3. Введите **Логин** и **Пароль**
4. Нажмите **Войти**

#### Мобильное приложение

1. Установите приложение из магазина
2. Запустите приложение
3. При первом запуске введите:
   - **Адрес сервера:** IP-адрес или доменное имя
   - **Логин:** ваш логин
   - **Пароль:** ваш пароль
4. Нажмите **Войти**
5. При необходимости сохраните учетные данные

#### Desktop приложение

1. Установите приложение
2. Запустите приложение
3. При первом запуске введите адрес сервера
4. Введите **Логин** и **Пароль**
5. Нажмите **Войти**

### Интерфейс системы

После входа вы увидите главный экран с:
- **Дашборд:** обзор системы, активные камеры, последние события
- **Камеры:** список всех доступных камер
- **Записи:** архив видеозаписей
- **События:** список событий системы
- **Профиль:** настройки вашего профиля

## Просмотр камер

### Список камер

1. Перейдите в раздел **Камеры**
2. Вы увидите список всех доступных камер
3. Для каждой камеры отображается:
   - Название камеры
   - Статус (ONLINE - работает, OFFLINE - недоступна)
   - Миниатюра последнего кадра
   - Количество новых событий (если есть)

### Просмотр видеопотока

1. Откройте камеру из списка (кликните на карточку)
2. Видеопоток откроется в отдельном окне
3. Используйте элементы управления:
   - **▶️ Воспроизведение/Пауза:** для остановки/возобновления потока
   - **🔊 Звук:** включить/выключить звук, регулировка громкости
   - **⛶ Полноэкранный режим:** для просмотра на весь экран
   - **📸 Скриншот:** сохранение текущего кадра
   - **⚙️ Настройки:** выбор качества потока (если доступно)

### Многокамерный просмотр

Для одновременного просмотра нескольких камер:

1. Перейдите в **Просмотр** → **Многокамерный**
2. Выберите макет:
   - **1 камера:** полноэкранный просмотр
   - **4 камеры:** сетка 2x2
   - **9 камер:** сетка 3x3
   - **16 камер:** сетка 4x4
3. Выберите камеры для отображения
4. Камеры можно перетаскивать для изменения позиции

### Фильтрация камер

Используйте фильтры для поиска нужных камер:
- **По статусу:** показать только ONLINE или OFFLINE камеры
- **По названию:** поиск по тексту в названии
- **По группе:** если камеры организованы в группы (например, "Парковка", "Вход")

## Просмотр записей

### Доступ к записям

1. Перейдите в раздел **Записи**
2. Записи отображаются в виде списка или календаря

### Поиск записей

Используйте фильтры для поиска нужных записей:

- **По камере:** выберите одну или несколько камер
- **По дате:** выберите дату или диапазон дат
- **По времени:** укажите время начала и окончания
- **По типу события:** если запись связана с событием (движение, объект и т.д.)

### Просмотр записи

1. Откройте запись из списка
2. Видеоплеер откроется с записью
3. Используйте элементы управления:
   - **▶️ Воспроизведение/Пауза**
   - **⏮️⏭️ Перемотка:** кнопки назад/вперед или перетаскивание ползунка
   - **⏩ Скорость:** изменение скорости воспроизведения (0.5x, 1x, 1.5x, 2x)
   - **⏸️ Кадр за кадром:** для детального просмотра
   - **🔊 Звук:** включить/выключить звук
   - **⛶ Полноэкранный режим**

### Экспорт записи

Если у вас есть разрешение на экспорт:

1. Откройте запись
2. Нажмите кнопку **Экспорт**
3. Выберите параметры:
   - **Формат:** MP4 (рекомендуется), AVI, MKV
   - **Качество:** оригинал, высокое, среднее, низкое
   - **Диапазон:** весь файл или выбранный фрагмент (укажите время начала и окончания)
4. Нажмите **Экспортировать**
5. Дождитесь завершения обработки
6. Скачайте файл

**Примечание:** Экспорт больших файлов может занять некоторое время.

## Просмотр событий

### Список событий

1. Перейдите в раздел **События**
2. События отображаются в хронологическом порядке (новые сверху)
3. Для каждого события отображается:
   - Тип события (движение, обнаружен объект, распознан номер и т.д.)
   - Камера, на которой произошло событие
   - Дата и время
   - Миниатюра события
   - Статус (новое, просмотренное)

### Фильтрация событий

Используйте фильтры для поиска нужных событий:

- **По типу:** движение, объект, ANPR (номер), лицо
- **По камере:** выберите одну или несколько камер
- **По дате:** выберите дату или диапазон дат
- **По статусу:** новые, просмотренные, подтвержденные

### Просмотр деталей события

1. Откройте событие из списка (кликните на карточку)
2. Откроется детальная информация:
   - Видео события (если доступно)
   - Миниатюры до и после события
   - Детектированные объекты (если включена аналитика)
   - Дополнительная информация (координаты, размеры объектов)
3. Можно просмотреть связанную запись, нажав **Просмотреть запись**

### Экспорт событий

Если у вас есть разрешение:

1. Выберите события в списке (можно использовать фильтры)
2. Нажмите кнопку **Экспорт**
3. Выберите формат:
   - **CSV:** таблица с данными событий (для Excel)
   - **PDF:** отчет с миниатюрами и описаниями
   - **Видео:** экспорт видео событий в один файл
4. Нажмите **Экспортировать**
5. Скачайте файл

## Настройки профиля

### Изменение информации профиля

1. Перейдите в **Профиль** (иконка пользователя в правом верхнем углу)
2. Измените информацию:
   - **Полное имя:** ваше отображаемое имя
   - **Email:** адрес электронной почты
3. Нажмите **Сохранить**

### Смена пароля

1. Перейдите в **Профиль** → **Безопасность**
2. Введите:
   - **Текущий пароль**
   - **Новый пароль**
   - **Подтверждение нового пароля**
3. Нажмите **Изменить пароль**

**Рекомендации по паролю:**
- Минимум 8 символов
- Используйте буквы, цифры и специальные символы
- Не используйте простые пароли (123456, password и т.д.)

### Настройки уведомлений

1. Перейдите в **Профиль** → **Уведомления**
2. Выберите каналы уведомлений:
   - **Push-уведомления:** уведомления в приложении
   - **Email:** уведомления на электронную почту
   - **SMS:** уведомления на телефон (если настроено администратором)
3. Выберите типы событий, о которых хотите получать уведомления
4. Нажмите **Сохранить**

### Настройки интерфейса

1. Перейдите в **Профиль** → **Интерфейс**
2. Настройте:
   - **Тема:** светлая, темная, автоматическая (следует системным настройкам)
   - **Язык:** выберите язык интерфейса
   - **Часовой пояс:** для корректного отображения времени
   - **Формат даты/времени:** выберите предпочитаемый формат
3. Нажмите **Сохранить**

### Настройки просмотра

1. Перейдите в **Профиль** → **Просмотр**
2. Настройте:
   - **Качество по умолчанию:** для видеопотоков (автоматически, высокое, среднее, низкое)
   - **Автозапуск:** автоматическое воспроизведение при открытии записи
   - **Буферизация:** настройки буфера для плавного воспроизведения
3. Нажмите **Сохранить**

## Мобильные приложения

### Установка приложения

#### Android

1. Откройте Google Play Store
2. Найдите "IP Camera Surveillance"
3. Нажмите **Установить**
4. После установки откройте приложение

#### iOS

1. Откройте App Store
2. Найдите "IP Camera Surveillance"
3. Нажмите **Получить** или **Установить**
4. После установки откройте приложение

### Первая настройка

1. При первом запуске введите:
   - **Адрес сервера:** IP-адрес или доменное имя (например, `192.168.1.100` или `surveillance.company.com`)
   - **Порт:** обычно 8080 для HTTP или 8443 для HTTPS (если отличается от стандартного)
   - **Логин:** ваш логин
   - **Пароль:** ваш пароль
2. Нажмите **Войти**
3. При необходимости сохраните учетные данные для быстрого входа

### Основные функции

#### Просмотр камер

1. Откройте раздел **Камеры**
2. Выберите камеру из списка
3. Видеопоток откроется в полноэкранном режиме
4. Используйте жесты:
   - **Касание:** показать/скрыть элементы управления
   - **Свайп влево/вправо:** переключение между камерами
   - **Пинч:** масштабирование (если поддерживается)

#### Просмотр записей

1. Откройте раздел **Записи**
2. Выберите запись из списка
3. Видеоплеер откроется с записью
4. Используйте элементы управления для воспроизведения

#### Уведомления

Приложение может отправлять push-уведомления о событиях:
1. Разрешите уведомления при первом запуске
2. Настройте типы событий в **Профиль** → **Уведомления**
3. Уведомления будут приходить даже когда приложение закрыто

#### Офлайн режим

Некоторые функции доступны офлайн:
- Просмотр ранее загруженных записей
- Просмотр кэшированных миниатюр
- Просмотр списка камер (без видеопотока)

## Часто задаваемые вопросы

### Общие вопросы

**Q: Как получить доступ к системе?**  
A: Обратитесь к администратору для получения учетных данных (логин и пароль).

**Q: Можно ли использовать систему с мобильного устройства?**  
A: Да, система доступна через веб-браузер на любом устройстве, а также через мобильные приложения для Android и iOS.

**Q: Нужен ли интернет для работы системы?**  
A: Для просмотра видеопотоков в реальном времени требуется подключение к сети, где находится сервер. Интернет не обязателен, если вы находитесь в локальной сети.

**Q: Можно ли просматривать записи офлайн?**  
A: В мобильных приложениях можно просматривать ранее загруженные записи офлайн. В веб-интерфейсе требуется подключение к серверу.

### Просмотр видео

**Q: Видео не воспроизводится или показывает черный экран**  
A: Проверьте подключение к сети. Если проблема сохраняется, обратитесь к администратору.

**Q: Видео тормозит или прерывается**  
A: Это может быть связано с медленным интернет-соединением. Попробуйте снизить качество видеопотока в настройках.

**Q: Как сделать скриншот?**  
A: Во время просмотра видеопотока нажмите кнопку скриншота. Изображение будет сохранено в папку загрузок.

### Записи

**Q: Как найти запись за определенную дату?**  
A: Используйте фильтр по дате в разделе **Записи**. Выберите нужную дату или диапазон дат.

**Q: Можно ли экспортировать запись?**  
A: Да, если у вас есть разрешение. Откройте запись и нажмите кнопку **Экспорт**. Выберите формат и параметры.

**Q: Как долго хранятся записи?**  
A: Срок хранения записей определяется администратором. Обычно записи хранятся от 7 до 30 дней, но это может варьироваться.

### События

**Q: Что такое события?**  
A: События - это автоматически зафиксированные моменты, когда система обнаружила движение, объекты, номера автомобилей или лица на камерах.

**Q: Как получать уведомления о событиях?**  
A: Настройте уведомления в **Профиль** → **Уведомления**. Выберите каналы (push, email) и типы событий.

**Q: Можно ли экспортировать список событий?**  
A: Да, если у вас есть разрешение. Выберите события и нажмите **Экспорт**. Выберите формат (CSV, PDF, видео).

### Технические вопросы

**Q: Какие браузеры поддерживаются?**  
A: Рекомендуются современные браузеры: Chrome, Firefox, Safari, Edge версии не старше 2 лет.

**Q: Работает ли система на планшетах?**  
A: Да, система работает на планшетах через веб-браузер или мобильное приложение.

**Q: Можно ли использовать систему на нескольких устройствах одновременно?**  
A: Да, вы можете войти в систему с нескольких устройств одновременно.
