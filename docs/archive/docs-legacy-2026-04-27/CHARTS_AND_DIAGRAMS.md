## 🔧 Генерация графиков

Для генерации визуальных графиков используйте скрипт:

```bash
python scripts/generate-readiness-charts.py
```

**Требования:**
- Python 3.7+
- matplotlib
- numpy

**Установка зависимостей:**
```bash
pip install matplotlib numpy
```

**Созданные файлы:**
- `docs/charts/readiness_bar_chart.png` - Карта готовности по блокам
- `docs/charts/progress_pie_chart.png` - Распределение блоков по статусу
- `docs/charts/roadmap_chart.png` - Карта реализации до конца года
- `docs/charts/detailed_decomposition.png` - Детальная декомпозиция
- `docs/charts/test_coverage_chart.png` - Покрытие тестами
- `docs/charts/blockers_chart.png` - Критические блокеры
