## Поддерживаемые кодеки

### H.264 (AVC)

**Описание:** Наиболее распространенный кодек для видеонаблюдения

**Преимущества:**
- Широкая поддержка устройств
- Хорошее качество при низком битрейте
- Аппаратное ускорение на большинстве устройств

**Недостатки:**
- Больший размер файлов чем H.265
- Выше требования к пропускной способности

**Использование:**
```yaml
video:
  codec: h264
  preset: medium
  bitrate: 2000  # kbps
```

**Аппаратное ускорение:**
- NVIDIA: `h264_nvenc`
- Intel: `h264_qsv`
- AMD: `h264_amf`

---

### H.265 (HEVC)

**Описание:** Более эффективный кодек, преемник H.264

**Преимущества:**
- На 50% меньший размер файлов при том же качестве
- Лучшее качество при низком битрейте
- Поддержка 4K и выше

**Недостатки:**
- Выше требования к CPU
- Меньше поддержки старых устройств

**Использование:**
```yaml
video:
  codec: h265
  preset: medium
  bitrate: 1500  # kbps (меньше чем H.264)
```

**Аппаратное ускорение:**
- NVIDIA: `hevc_nvenc`
- Intel: `hevc_qsv`
- AMD: `hevc_amf`

---

### MJPEG

**Описание:** Motion JPEG - последовательность JPEG изображений

**Преимущества:**
- Простота декодирования
- Хорошее качество для статичных сцен
- Низкая задержка

**Недостатки:**
- Большой размер файлов
- Высокий битрейт

**Использование:**
```yaml
video:
  codec: mjpeg
  quality: 85  # JPEG quality (0-100)
```

## Форматы контейнеров

### MP4

**Описание:** Наиболее распространенный формат

**Преимущества:**
- Широкая поддержка
- Хорошая совместимость

**Использование:**
```yaml
recording:
  format: mp4
  container: mp4
```

### MKV

**Описание:** Открытый формат контейнера

**Преимущества:**
- Поддержка множества кодеков
- Хорошая поддержка метаданных

**Использование:**
```yaml
recording:
  format: mkv
  container: mkv
```

## Рекомендации по выбору кодека

### Для записи

- **H.264:** Рекомендуется для большинства случаев
- **H.265:** Для экономии места на диске
- **MJPEG:** Для специальных случаев (низкая задержка)

### Для потоковой передачи

- **H.264:** Для максимальной совместимости
- **H.265:** Для экономии пропускной способности
