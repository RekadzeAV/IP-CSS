- `ScreenshotService` - создание снимков

### Управление ресурсами

- Ограничение размера буфера для управления памятью

### Производительность
- Оптимизированная буферизация с ограничением размера

- Асинхронная обработка через корутины

## Требования

### Зависимости
- FFmpeg установлен и доступен в PATH
- ExoPlayer (Media3) 1.2.1+ для Android
- HLS.js 1.5.12+ для веб-интерфейса

### Конфигурация
- `streams/hls/` - директория для HLS сегментов
- `screenshots/` - директория для снимков
- `maxBufferSize = 50` - размер буфера кадров
- `streamTimeoutMinutes = 30` - таймаут неактивного стрима

## Известные ограничения

1. **Декодирование кадров**: Прямое декодирование H.264 кадров из `RtspFrame` не реализовано. Используется FFmpeg для снимков.

2. **HLS сегменты**: Сегменты не удаляются автоматически сразу после остановки стрима (для возможности перемотки).

3. **Изменение качества**: Требует перезапуска HLS генерации, может вызвать кратковременное прерывание.
