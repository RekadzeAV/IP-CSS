## 🟢 Настоящее (Текущая разработка)

### Версия Alfa-0.0.1 - Декабрь 2025 (В разработке)
**🏗️ Инфраструктура и базовая функциональность**

**Текущий прогресс:** ~20% от MVP

#### ✅ Завершено

**Инфраструктура (100%):**
- ✅ Модульная структура проекта (shared, core, native, server)
- ✅ Gradle конфигурация для всех модулей с Kotlin Multiplatform
- ✅ Version Catalog (`gradle/libs.versions.toml`)
- ✅ Поддержка платформ: Android, iOS (x64, arm64, simulator), Desktop (JVM)
- ✅ SQLDelight настройка и схемы
- ✅ Полная документация (ARCHITECTURE, API, DEPLOYMENT, etc.)
- ✅ CI/CD пайплайны (.github/workflows/ci.yml, cd.yml)
- ✅ Dockerfile для серверной части
- ✅ docker-compose.yml исправлен и готов к использованию

**Доменный слой (~30%):**
- ✅ Модель Camera с полной структурой
- ✅ Модели данных: Recording, Event, User, License, Settings, Notification
- ✅ Интерфейс CameraRepository
- ✅ 5 Use Cases для управления камерами:
  - AddCameraUseCase
  - GetCamerasUseCase
  - GetCameraByIdUseCase
  - UpdateCameraUseCase
  - DeleteCameraUseCase

**Слой данных (~50%):**
- ✅ SQLDelight схема для камер
- ✅ CameraRepositoryImpl с CRUD операциями
- ✅ CameraEntityMapper (domain ↔ database)
- ✅ DatabaseFactory для Android и iOS
- ✅ Unit тесты для репозитория и use cases

**Сетевой слой (~40%):**
- ✅ ApiClient (HTTP клиент с retry, cache, error handling) - полностью реализован
- ✅ API сервисы (интерфейсы): CameraApiService, RecordingApiService, etc.
- ✅ DTO модели для API
- ⚠️ OnvifClient (частично - ~40%, WS-Discovery частично реализован)
- ⚠️ WebSocketClient (частично - ~80%, базовая функциональность есть)
- ⚠️ RtspClient (частично - ~10%, требует интеграции с нативной библиотекой)

**Лицензирование (~20%):**
- ⚠️ LicenseManager (частично - ~20%, онлайн/офлайн активация не реализованы)
- ⚠️ Платформо-специфичные реализации (частично - Android/iOS используют временные решения)

**Серверная часть (~30%):**
- ✅ REST API сервер (Ktor) - базовые endpoints для камер реализованы
- ✅ База данных сервера (SQLDelight, используется локально)
- ✅ Веб-интерфейс (Next.js) - базовая структура и экраны камер реализованы
- ❌ WebSocket сервер
- ❌ Аутентификация и авторизация

#### ⚠️ В процессе

**Критические задачи (блокеры MVP):**
- ⚠️ Завершение OnvifClient (WS-Discovery)
- ⚠️ Завершение веб-интерфейса (события, записи, настройки, видеоплеер)
- ⚠️ Добавление аутентификации (JWT, middleware, RBAC)
- ⚠️ Реализация RTSP клиента

**Статус:** 🟡 В активной разработке

## 🔮 Будущее (Планы развития)

### Фаза 1: MVP (Минимально жизнеспособный продукт)
**⏱️ Оценка времени:** 4-7 месяцев  
**🎯 Цель:** Создать рабочую версию для одной-двух платформ с базовым функционалом

#### 1.1 Завершение серверной части (2-3 месяца)

**Задачи:**
- ✅ Завершить REST API сервер
  - ✅ Реализовать все CRUD операции для всех сущностей
  - ❌ Добавить аутентификацию и авторизацию (JWT)
  - ❌ Реализовать WebSocket сервер для real-time обновлений
  - ❌ Добавить валидацию запросов и обработку ошибок

- ⚠️ Завершить веб-интерфейс
  - ⚠️ Завершить все экраны (события, записи, настройки)
  - ❌ Реализовать видеоплеер для RTSP потоков
  - ❌ Добавить WebSocket интеграцию
  - ❌ Улучшить UX и дизайн

**Критерии готовности:**
- ✅ Все API endpoints работают
- ⚠️ Веб-интерфейс полностью функционален
- ❌ Аутентификация работает
- ❌ Real-time обновления работают через WebSocket

#### 1.2 Реализация RTSP клиента (1-2 месяца)

**Задачи:**
- ❌ Реализовать нативный RTSP клиент на C++
- ❌ Создать Kotlin обертки через FFI
- ❌ Интегрировать с видеоплеером в веб-интерфейсе
- ❌ Добавить поддержку различных кодеков (H.264, H.265, MJPEG)

**Критерии готовности:**
- ❌ RTSP потоки воспроизводятся в веб-интерфейсе
- ❌ Поддержка основных кодеков
- ❌ Стабильная работа с несколькими камерами

#### 1.3 Базовая система записи (1-2 месяца)

**Задачи:**
- ❌ Реализовать запись RTSP потоков на диск
- ❌ Добавить управление записями (старт/стоп/пауза)
- ❌ Реализовать просмотр записей
- ❌ Добавить базовую систему хранения

**Критерии готовности:**
- ❌ Запись работает для одной камеры
- ❌ Просмотр записей работает
- ❌ Базовое управление записями работает

**Итого Фаза 1:** 4-7 месяцев

   - RBAC система

   - Убрать SYS_ADMIN
   - Настроить seccomp профиль

   - Убрать cleartext traffic
   - Настроить reverse proxy

4. **Реализация certificate pinning** (1 неделя)
   - Для всех платформ

   - Удалить anyHost()
   - Настроить whitelist доменов
