## 🚀 Рекомендации для завершения сборки

### Вариант 1: Восстановить Gradle Wrapper

```bash
# Если есть Git
git checkout gradlew gradlew.bat gradle/wrapper/

# Или создать заново
gradle wrapper --gradle-version 8.4
```

### Вариант 2: Установить Gradle глобально

```powershell
# Через Chocolatey
choco install gradle

# Или скачать с https://gradle.org/install/
```

### Вариант 3: Использовать WSL или Git Bash

```bash
# В WSL или Git Bash
./scripts/build-nas-package.sh synology x86_64 Alfa-0.0.1
```

### Вариант 4: Использовать Docker

```bash
# Собрать в Docker контейнере с Gradle
docker run --rm -v ${PWD}:/project -w /project gradle:8.4-jdk17 gradle :server:api:build
```
