## ❌ Проблемы

### Проблема 1: Зависимости Gradle

**Ошибка:**
```
Plugin [id: 'app.cash.sqldelight', version: '2.0.3', apply: false] was not found
```

**Причина:** Плагин `sqldelight` не может быть найден в репозиториях.

**Возможные решения:**

1. **Проверить доступность интернета:**
   ```powershell
   Test-NetConnection mavenCentral.org -Port 443
   ```

2. **Обновить версию плагина** в `build.gradle.kts`:
   - Текущая версия: `2.0.3`
   - Попробовать более новую версию или другую

3. **Добавить репозиторий** для плагина в `settings.gradle.kts`:
   ```kotlin
   pluginManagement {
       repositories {
           google()
           mavenCentral()
           gradlePluginPortal()
           maven { url = uri("https://oss.sonatype.org/content/repositories/snapshots/") }
       }
   }
   ```

4. **Временно отключить проблемные модули** для сборки только API сервера

## 🚀 Альтернативные варианты сборки

### Вариант 1: Использовать WSL или Git Bash

Если у вас установлен WSL или Git Bash, можно использовать оригинальный bash скрипт:

```bash
# В WSL или Git Bash
./scripts/build-nas-package.sh synology x86_64 Alfa-0.0.1
```

### Вариант 2: Собрать вручную без API сервера

Если нужно создать пакет для тестирования структуры (без функциональности):

1. Создать пустой JAR файл:
   ```powershell
   New-Item -ItemType Directory -Path "server\api\build\libs" -Force
   # Создать минимальный JAR (только для тестирования структуры пакета)
   ```

2. Запустить сборку пакета (веб-интерфейс можно пропустить)

### Вариант 3: Исправить зависимости и собрать полностью

1. Исправить проблему с `sqldelight` плагином
2. Собрать API сервер: `.\gradlew.bat :server:api:build`
3. Собрать веб-интерфейс: `cd server\web && npm install && npm run build`
4. Запустить сборку пакета: `.\scripts\build-nas-package.ps1 -PackageType synology -Arch x86_64`
