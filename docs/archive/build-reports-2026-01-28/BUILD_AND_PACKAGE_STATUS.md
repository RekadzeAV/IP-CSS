## 📝 Рекомендации

### Для успешной сборки API сервера:

1. **Исправить SQLDelight диалект:**
   - Обновить до SQLite 3.35+ или изменить SQL запросы
   - Убрать `ON CONFLICT DO UPDATE` или использовать альтернативный подход

2. **Исправить зависимости:**
   - Проверить доступность `ktor-client-http-cookies:2.3.12`
   - Обновить версию или использовать альтернативный репозиторий

3. **Исправить PowerShell скрипт:**
   - Проверить синтаксис `build-video-processing-lib.ps1`
   - Исправить ошибки парсинга

4. **Собрать нативные библиотеки:**
   - Исправить скрипт сборки или отключить задачу сборки нативных библиотек

### Для создания SPK пакета:

1. **Собрать API сервер JAR:**
   ```powershell
   .\gradlew.bat :server:api:jar --no-daemon
   ```

2. **Собрать веб-интерфейс (опционально):**
   ```powershell
   cd server\web
   npm install
   npm run build
   ```

3. **Создать SPK пакет:**
   ```powershell
   .\scripts\build-nas-package.ps1 -PackageType synology -Arch x86_64 -Version Alfa-0.0.1
   ```
