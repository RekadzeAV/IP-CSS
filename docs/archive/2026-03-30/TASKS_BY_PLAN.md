## 1. Фаза 1 (MVP) — дорожная карта по неделям

Соответствие этапам плана: **Этап 0–1** (foundation + data/server), **Этап 2** (1.4 + 1.8), **Этап 3** (1.6 web), **Этап 4** (1.9 security), **Этап 5** (1.7 platforms), **Этап 6** (1.10 tests + go/no-go).

### Неделя 1 — Foundation + data/server baseline + старт транспорта

- [ ] **W1-0** Зафиксировать must-have сценарии MVP и границы приёмки (согласовать iOS/Desktop вне блокеров при необходимости).
- [ ] **W1-1** Довести миграции БД, smoke/rollback; закрыть хвост **repository V2** (1.3.5).
- [ ] **W1-2** PostgreSQL: staging cutover + rollback rehearsal по runbook (1.5.6).
- [ ] **W1-3** Старт **Этапа 2**: RTSP native integration + HLS runtime (long-run, reconnect, cleanup); screenshot `captureFrame(...)` (1.8).

### Неделя 2 — Завершение видео-транспорта + ONVIF

- [ ] **W2-1** Закрыть production-path: discover → play → record → replay → events (без деградации на длительных прогонах).
- [ ] **W2-2** Ручная валидация **ONVIF Events** на целевых камерах; зафиксировать отчёт (связано с P1-2 / F1-2).
- [ ] **W2-3** Стабилизация HLS pipeline и FFmpeg/runtime (1.8.2).

### Неделя 3 — Web closure + Security MVP

- [ ] **W3-1** Полная интеграция **WebSocket** в web: подписки, **reconnect с backoff**, дедуп сообщений при необходимости (P1-1).
- [ ] **W3-2** **Безопасное хранение JWT** (httpOnly / refresh lifecycle) — закрыть P1-4.
- [ ] **W3-3** Видеоплеер web: интеграция с RTSP/HLS backend path (P1-3 / F1-3).
- [ ] **W3-4** Ручной perf-pass по [WEB_INTERFACE_PERF_MANUAL_CHECKLIST.md](../../status/WEB_INTERFACE_PERF_MANUAL_CHECKLIST.md) (если применимо).
- [ ] **W3-5** **Security MVP**: HTTPS enforcement, pinning на клиентах где применимо, минимальный аудит (P1-5, 1.9).

### Неделя 4 — Платформы + тесты + go/no-go

**Автоматизация и runbook:** [W4_MVP_PLATFORM_SMOKE_RUNBOOK.md](../../reports/W4_MVP_PLATFORM_SMOKE_RUNBOOK.md) · `scripts/w4-mvp-platform-and-gate.ps1` · раздел W4 в [RELEASE_GO_NO_GO_CHECKLIST.md](../../planning/RELEASE_GO_NO_GO_CHECKLIST.md).

- [ ] **W4-1** Android: video + background recording — стабильный сценарий (1.7.2, 1.8.7).
- [ ] **W4-2** Desktop: long-run видеоплеер и события; ARM/x86 smoke (1.7.3).
- [ ] **W4-3** Integration-тесты: API, БД/миграции, критичный video path (1.10.2–1.10.3).
- [ ] **W4-4** Минимальный E2E smoke для критических пользовательских сценариев (1.10.4).
- [ ] **W4-5** Финальная матрица приёмки и **GO/NO-GO** ([RELEASE_GO_NO_GO_CHECKLIST.md](../../planning/RELEASE_GO_NO_GO_CHECKLIST.md), отчёты в `docs/reports/`).
