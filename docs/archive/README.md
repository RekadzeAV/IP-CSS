```
│   └── [старые документы]

```

---

## 🔄 Процесс версионирования

При оптимизации или обновлении документации:

1. **Версия документа увеличивается на 1** (например, 2.0 → 3.0)
2. **Исходная версия копируется** в каталог `docs/archive/YYYY-MM-DD/`
3. **Создается папка на дату** внесения изменений (формат: `YYYY-MM-DD`)
4. **Обновляется метаданные** в документе (версия, дата обновления)

### Формат версионирования

- **Мажорная версия** (например, 2.0 → 3.0): значительные изменения структуры или содержания
- **Минорная версия** (например, 2.0 → 2.1): небольшие дополнения или исправления
- **Патч-версия** (например, 2.0 → 2.0.1): исправления ошибок

## 🔍 Как найти старую версию документа

1. Определите дату последнего изменения документа (указана в метаданных)
2. Найдите соответствующую папку в `docs/archive/YYYY-MM-DD/`
3. Найдите нужный документ по имени

### Пример

Если документ `ARCHITECTURE.md` был обновлен 15 февраля 2025:
- Старая версия будет в `docs/archive/2025-02-15/ARCHITECTURE.md`
- Текущая версия в `docs/ARCHITECTURE.md`
