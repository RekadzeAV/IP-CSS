## 2. Завершение ONVIF WS-Discovery (70% → 98%)

### Выполненные улучшения:

#### 2.1 Оптимизация множественных Probe запросов
- ✅ Реализована адаптивная стратегия отправки (4 запроса с увеличивающимися интервалами)
- ✅ Добавлена проверка количества ответов для раннего прекращения
- ✅ Оптимизированы интервалы между запросами (0ms, 500ms, 1000ms, 1500ms)
- ✅ Применено ко всем платформам (JVM, Android, Native, iOS)

**Файлы:**
- `core/network/src/jvmMain/kotlin/com/company/ipcamera/core/network/WSDiscovery.jvm.kt`
- `core/network/src/androidMain/kotlin/com/company/ipcamera/core/network/WSDiscovery.android.kt`
- `core/network/src/nativeMain/kotlin/com/company/ipcamera/core/network/WSDiscovery.native.kt`
- `core/network/src/iosMain/kotlin/com/company/ipcamera/core/network/WSDiscovery.ios.kt`

**Изменения:**
```kotlin
// Было: 2 запроса с фиксированным интервалом 500ms
// Стало: 4 запроса с адаптивными интервалами и ранним прекращением
// Применено для всех платформ
```

#### 2.2 Улучшение XML парсинга
- ✅ Улучшена обработка различных форматов namespace префиксов
- ✅ Добавлена поддержка поиска в атрибутах (некоторые устройства используют атрибуты)
- ✅ Улучшена обработка пробелов, табов и переносов строк
- ✅ Добавлена валидация URL в XAddrs
- ✅ Улучшена очистка и фильтрация данных
- ✅ Применено ко всем платформам

**Файлы:**
- `core/network/src/jvmMain/kotlin/com/company/ipcamera/core/network/WSDiscovery.jvm.kt`
- `core/network/src/androidMain/kotlin/com/company/ipcamera/core/network/WSDiscovery.android.kt`
- `core/network/src/nativeMain/kotlin/com/company/ipcamera/core/network/WSDiscovery.native.kt`
- `core/network/src/iosMain/kotlin/com/company/ipcamera/core/network/WSDiscovery.ios.kt`

**Изменения:**
```kotlin
// Улучшения:
- Поддержка различных регистров (XAddrs, xAddrs, xaddrs)
- Поиск в атрибутах узлов
- Валидация URL перед добавлением в результат
- Фильтрация пустых и некорректных значений
```

### Результат:
WS-Discovery теперь более надежно обнаруживает устройства, лучше обрабатывает различные форматы ответов и оптимизирует использование сетевых ресурсов.
