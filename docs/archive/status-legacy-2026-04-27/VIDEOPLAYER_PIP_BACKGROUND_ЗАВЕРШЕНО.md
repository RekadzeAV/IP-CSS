## Реализованные функции

### 1. Picture-in-Picture (PiP) режим

**Реализовано:**
- ✅ `PictureInPictureManager` - менеджер для управления PiP режимом
- ✅ Поддержка PiP в `MainActivity`:
  - Обработка `onPictureInPictureModeChanged`

  - Настройка системного UI
- ✅ Кнопка PiP в `VideoViewScreen`
- ✅ Автоматическое определение поддержки PiP на устройстве
- ✅ Настройка соотношения сторон (16:9)

**Файлы:**
- `android/app/src/main/java/com/company/ipcamera/android/media/PictureInPictureManager.kt`
- `android/app/src/main/java/com/company/ipcamera/android/MainActivity.kt`
- `android/app/src/main/java/com/company/ipcamera/android/ui/screens/video/VideoViewScreen.kt`

**AndroidManifest.xml:**
```xml
<activity
    android:supportsPictureInPicture="true"
    android:configChanges="screenSize|smallestScreenSize|screenLayout|orientation">
```

## Технические детали

### Picture-in-Picture

**Минимальные требования:**
- Android 8.0 (API 26) для базовой поддержки
- Android 12 (API 31) для улучшенной поддержки

**Особенности:**
- Соотношение сторон: 16:9 (настраивается)
- Автоматическое обновление параметров при изменении конфигурации
- Сохранение состояния воспроизведения при переходе в PiP

### Фоновое воспроизведение

**Особенности:**
- Использует Media3 MediaSession для совместимости с ExoPlayer
- Автоматическая синхронизация состояния плеера
- Поддержка медиа-кнопок в уведомлениях
- Управление через системные уведомления

**Уведомления:**
- Отображают метаданные (название камеры, статус)
- Кнопки управления (play/pause/stop)
- Автоматическое обновление при изменении состояния

## Известные ограничения

1. **Picture-in-Picture:**
   - Не все устройства поддерживают PiP (требуется проверка)
   - Некоторые производители могут ограничивать функциональность

2. **Фоновое воспроизведение:**
   - Может быть ограничено политиками энергосбережения
   - Требует разрешения на фоновую работу (уже добавлено)
