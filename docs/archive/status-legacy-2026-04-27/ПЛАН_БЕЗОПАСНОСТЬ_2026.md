## 1. Certificate Pinning (50% → 100%)

### 1.1 Анализ текущего состояния

**Что уже реализовано:**
- ✅ Android: Базовая реализация через OkHttp CertificatePinner
- ✅ iOS: Полная реализация через CertificatePinningDelegate
- ✅ JVM: Реализация через кастомный TrustManager
- ✅ ApiClient: Интеграция с certificate pinning через `createEngineWithCertificatePinning`

**Что нужно доработать:**
- ❌ OnvifClient не использует certificate pinning
- ❌ WebSocketClient может использовать HTTP для upgrade, нужна проверка
- ❌ Нет централизованной конфигурации certificate pins
- ❌ Нет документации по настройке pins для production
