# ONVIF Events: поддерживаемый профиль (MVP)

Дата: 2026-03-27  
Область: `1.4.6 ONVIF Event service (PullPoint + mapping)`

## Цель

Зафиксировать минимальный поддерживаемый профиль камер для стабильной работы ONVIF Events в MVP,
пока полная валидация 6/6 камер не завершена.

## Поддерживаемый профиль (MVP)

Камера считается **поддерживаемой для ONVIF Events**, если выполняются все пункты:

- ONVIF Device Service доступен по HTTP/HTTPS.
- `GetCapabilities` возвращает Event Service URL (`Events/XAddr`).
- Камера поддерживает PullPoint (`CreatePullPointSubscription` успешно).
- `PullMessages` возвращает 2xx (допустимы пустые ответы и штатные timeout).
- `Renew` и `SetSynchronizationPoint` выполняются без фатальных ошибок.
- ONVIF topic корректно маппится в доменную модель через `OnvifEventMapper`.

## Статус покрытия (текущий)

- Проверено успешно: **4/6 камер**.
- Не подтверждено: **2/6 камер** (требуется отдельная проверка прав/прошивки/профиля событий).

## Что считается штатным поведением

- Периодические timeout в PullPoint polling — нормальный сценарий, не трактуется как инцидент.
- Пустой пакет сообщений от `PullMessages` — нормальный сценарий при отсутствии новых событий.

## Известные ограничения MVP

- Нет гарантии совместимости для камер, не соответствующих поддерживаемому профилю выше.
- Для камер без PullPoint-поддержки требуется отдельная стратегия (push/basic notification).
- Полная межвендорная матрица совместимости пока не зафиксирована.
