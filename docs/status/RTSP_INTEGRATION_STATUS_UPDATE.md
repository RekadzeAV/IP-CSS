- ❌ pkg-config не найден

### 2. Библиотека не скомпилирована
- ❌ Нет `libvideo_processing.so/dylib/dll`
- ❌ Нет экспортированных символов

- ❌ Импорты отключены

### 4. Аудио декодирование отключено
- ❌ Проблемы с FFmpeg 8.0 API
- ❌ `audio_decoder.cpp` временно отключен

## 📋 Детальный план доработки

### План создан: [docs/rtsp/RTSP_INTEGRATION_PLAN.md](../rtsp/RTSP_INTEGRATION_PLAN.md)

**Оценка времени:**
- **MVP (базовая функциональность):** 2-3 недели
- **Полная реализация:** 4-5 недель

### Этапы реализации

#### Этап 1: Подготовка окружения (1-2 дня)
- Установка CMake, FFmpeg, pkg-config
- Проверка CMake конфигурации

#### Этап 2: Компиляция библиотеки (1-2 дня)
- Сборка `libvideo_processing` для Desktop
- Проверка экспорта символов

#### Этап 3: Генерация биндингов (1 день)
- Запуск `./gradlew :core:network:compileKotlinLinuxX64`
- Проверка сгенерированных файлов

#### Этап 4: Активация кода (1-2 дня)
- Раскомментировать импорты в `NativeRtspClient.native.kt`
- Реализовать вызовы нативных функций
- Реализовать callback'и с StableRef

#### Этап 5: Базовое тестирование (2-3 дня)
- Unit тесты для всех методов
- Интеграционные тесты с реальной камерой
- E2E тест с видеоплеером

#### Этап 6: Аудио декодирование (3-5 дней)
- Исправить `audio_decoder.cpp` для FFmpeg 8.0
- Включить в сборку
- Протестировать AAC, PCMU, PCMA

#### Этап 7: Платформенная поддержка (1-2 недели)
- Android (arm64-v8a, armeabi-v7a)
- iOS (arm64)
- Настройка кросс-компиляции

#### Этап 8: Оптимизация (3-5 дней)
- Автоматическое переподключение
- TCP fallback при проблемах с UDP
- Улучшение задержки (< 2 сек)
