## Общая информация

Проект содержит три основные нативные C++ библиотеки, расположенные в директории `native/`:
1. **video-processing** - обработка видео и RTSP клиент
2. **analytics** - аналитика (детекция объектов, лиц, распознавание номеров)
3. **codecs** - управление кодеками (H.264, H.265, MJPEG)

Все библиотеки используют CMake для сборки и поддерживают кроссплатформенную компиляцию (Linux, macOS, Windows).
