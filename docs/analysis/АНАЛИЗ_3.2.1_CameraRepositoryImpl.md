#### 1.1 Создание класса CameraCache

**Файл:** `shared/src/commonMain/kotlin/com/company/ipcamera/shared/data/repository/CameraCache.kt`

**Требования:**
- Thread-safe реализация (использовать `ConcurrentHashMap` или `Mutex`)
- Поддержка TTL для записей
- Методы для добавления, получения, удаления и очистки
- Инвалидация кэша при обновлении/удалении камер

**Интерфейс:**
```kotlin

    private val ttlMillis: Long = 60_000 // 1 минута по умолчанию

    suspend fun get(key: String): Camera?
    suspend fun put(key: String, value: Camera)
    suspend fun remove(key: String)
```

**Детали реализации:**
- Использовать `kotlinx.coroutines.sync.Mutex` для thread-safety
- Хранить timestamp последнего обновления для каждой записи
- Автоматическая очистка устаревших записей
- Поддержка кэширования списка всех камер

#### 1.2 Интеграция кэша в CameraRepositoryImpl

**Изменения в `CameraRepositoryImpl.kt`:**
- Добавить поле `private val cache: CameraCache`
- Инициализировать кэш в конструкторе
- Модифицировать методы:
  - `getCameras()` - проверять кэш перед обращением к БД
  - `getCameraById()` - проверять кэш перед обращением к БД
  - `addCamera()` - обновлять кэш после добавления
  - `updateCamera()` - обновлять кэш после обновления
  - `removeCamera()` - удалять из кэша после удаления

**Стратегия кэширования:**
- Cache-Aside pattern (Lazy Loading)
- При чтении: проверка кэша → если нет, загрузка из БД → сохранение в кэш

### Пример реализации CameraCache

```kotlin
internal class CameraCache(
    private val ttlMillis: Long = 60_000,
    private val maxSize: Int = 100
) {
    private val mutex = Mutex()
    private val cache = mutableMapOf<String, CacheEntry<Camera>>()
    private val allCamerasCache = AtomicReference<CacheEntry<List<Camera>>?>(null)

    data class CacheEntry<T>(
        val value: T,
        val timestamp: Long
    ) {
        fun isExpired(ttl: Long): Boolean {
            return System.currentTimeMillis() - timestamp > ttl
        }
    }

    suspend fun get(key: String): Camera? = mutex.withLock {
        val entry = cache[key] ?: return@withLock null
        if (entry.isExpired(ttlMillis)) {
            cache.remove(key)
            return@withLock null
        }
        entry.value
    }

    suspend fun getAll(): List<Camera>? = mutex.withLock {
        val entry = allCamerasCache.get() ?: return@withLock null
        if (entry.isExpired(ttlMillis)) {
            allCamerasCache.set(null)
            return@withLock null
        }
        entry.value
    }

    suspend fun put(key: String, value: Camera) = mutex.withLock {
        if (cache.size >= maxSize && !cache.containsKey(key)) {
            // LRU eviction
            val oldest = cache.minByOrNull { it.value.timestamp }
            oldest?.let { cache.remove(it.key) }
        }
        cache[key] = CacheEntry(value, System.currentTimeMillis())
    }

    suspend fun putAll(value: List<Camera>) = mutex.withLock {
        allCamerasCache.set(CacheEntry(value, System.currentTimeMillis()))
    }

    suspend fun remove(key: String) = mutex.withLock {
        cache.remove(key)
    }

    suspend fun clear() = mutex.withLock {
        cache.clear()
        allCamerasCache.set(null)
    }

    suspend fun invalidate() = clear()
}
```
