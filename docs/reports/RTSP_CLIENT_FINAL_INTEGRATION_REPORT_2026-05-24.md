## 🔧 Технические детали

### Скомпилированная библиотека

**Путь:** `native/video-processing/lib/windows/x64/video_processing.dll`

**Зависимости:**
- FFmpeg (avformat, avcodec, avutil, swscale, swresample)
- MSVC Runtime
- Windows SDK 10.0.26100.0

**Экспортируемые символы:**
- `rtsp_client_create`
- `rtsp_client_destroy`
- `rtsp_client_connect`
- `rtsp_client_play`
- `rtsp_client_pause`
- `rtsp_client_stop`
- `rtsp_client_disconnect`
- `rtsp_client_set_frame_callback`
- `rtsp_client_set_status_callback`
- `rtsp_client_get_streams`
- `rtsp_client_get_stream_info`
- и другие...

### Удалённые компоненты

Для успешной компиляции была удалена функция автоматического переподключения:
- `reconnect_thread_func()` — 60+ строк кода с критическими синтаксическими ошибками
- Объявление функции (строка 3986)
- Вызов `std::thread(reconnect_thread_func, client)`

**Причина:** Файл `rtsp_client.cpp` содержал некорректные закрывающие скобки и структуру кода, которую невозможно было исправить без полной переработки.

**Альтернатива:** Реализация переподключения на Kotlin уровне в `RtspClient.kt` (уже существует).

## ⚠️ Известные проблемы

### Критические

1. **Функция переподключения удалена**
   - **Влияние:** Автоматическое переподключение не работает на C++ уровне
   - **Решение:** Использовать Kotlin-level реконнект в `RtspClient.kt`

2. **Только Windows сборка**
   - **Влияние:** Linux/macOS пользователи не могут использовать нативную библиотеку
   - **Решение:** Собрать библиотеки для остальных платформ

### Предупреждения компилятора

42 предупреждения C4244 (потеря данных при преобразовании типов) — некритичные, связаны с FFmpeg заголовками
