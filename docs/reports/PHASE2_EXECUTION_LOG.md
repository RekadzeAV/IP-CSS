## 🚨 Identified Issues и решения

### Issue #1: Recording WS Lifecycle требует сервер

**Дата обнаружения:** 2026-04-28 10:00  
**Приоритет:** P0 (BLOCKER)  
**Статус:** 🟡 В решении

**Описание:**
Тесты Recording WS Lifecycle требуют запущенный сервер API и доступную камеру ONVIF.

**Варианты решения:**
1. **A:** Запустить сервер разработки локально
   - Команда: `.\gradlew.bat :server:api:run`
   - Требует: PostgreSQL (или in-memory), FFmpeg
   - Риск: Может занять 1-2 дня на настройку

2. **B:** Использовать Docker контейнер
   - Образ: `ip-camera-server:dev`
   - Требует: Docker installed
   - Риск: Может не быть готового образа

3. **C:** Создать mock сервер
   - Стек: Ktor + mock WebSocket
   - Требует: Разработка mock реализации
   - Риск: Mock может не покрывать все сценарии

4. **D:** Параллельно выполнять Задачу 2
   - Не требует сервера
   - Увеличивает canonical readiness
   - Риск: Не закрывает 1.8.E контрол

**Принятое решение:** Комбинированный подход
- Попытаться запустить сервер (Вариант A)
- Параллельно выполнять Задачу 2
- Если сервер не запустится за 1 день - перейти к Варианту C
