## 🔍 Рекомендации

### Вариант 1: Проверить статус Java процессов
```powershell
Get-Process java -ErrorAction SilentlyContinue | 
  Select-Object Id, CPU, WorkingSet, StartTime
```

### Вариант 2: Проверить логи Gradle
```powershell
Get-ChildItem -Recurse -Filter "*.log" | 
  Select-Object -First 10 FullName
```

### Вариант 3: Остановить и перезапустить сборку
```powershell
# Остановка
./gradlew.bat --stop

# Очистка
Remove-Item -Path ".gradle" -Recurse -Force -ErrorAction SilentlyContinue

# Пересборка
./gradlew.bat clean build -x test --no-daemon
```

### Вариант 4: Упростить сборку
```powershell
# Только серверная часть
./gradlew.bat :server:api:build -x test

# Только shared модуль
./gradlew.bat :shared:build -x test
```
