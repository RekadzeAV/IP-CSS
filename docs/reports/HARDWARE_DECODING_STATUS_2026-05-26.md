## 🔧 Техническая реализация

### Архитектура

```
HWDecoder (абстрактный класс)
    ├── HWDecoderDXVA2 (Windows)
    ├── HWDecoderVideoToolbox (macOS)
    └── HWDecoderFactory (создание декодера)
```

### DXVA2 Flow

```cpp
1. Проверка поддержки: HWDecoderDXVA2::isSupported()
2. Инициализация Direct3D 11: initD3D11()
3. Создание decoder: createDecoder()
4. Создание Output View: createDecoderOutputView()
5. Декодирование: decode()
6. Освобождение: releaseResources()
```

### Factory Flow

```cpp
1. HWDecoderFactory::create(codec, width, height)
2. Проверка поддержки: isDXVA2Supported() / isVideoToolboxSupported()
3. Создание декодера: std::make_unique<HWDecoderDXVA2>()
4. Инициализация: decoder->init()
5. Fallback на nullptr (программное) если не удалось
```

## ⚠️ Известные ограничения

### DXVA2

1. **Заглушка декодирования:**
   - Текущая реализация `decode()` выделяет память и копирует данные
   - Полная реализация требует:
     - Обработка NAL units
     - Создание decoder input buffers
     - Вызов `DecodePicture()`
     - Конвертация из DXVA2 формата в RGB/YUV

2. **Требуются тесты:**
   - Реальное оборудование с DXVA2 поддержкой
   - Тесты с H.264 и H.265 потоками
   - Проверка memory leaks

### VideoToolbox

1. **Не реализовано:**
   - Класс `HWDecoderVideoToolbox` — заглушка
   - VTDecompressionSession
   - CMVideoFormatDescription
   - Интеграция с RTSP клиентом
