## 🔁 Правила автоматизации

### Проверка сборки
```
1. Запуск сборки
2. Проверка результата:
   - Успех → следующая задача
   - Неудача → перейти к шагу 3
3. Анализ ошибок:
   - Извлечь логи
   - Определить категорию ошибки
   - Применить решение
4. Повторная сборка (макс 3 попытки)
5. Если 3 попытки без изменений:
   - ОСТАНОВИТЬСЯ
   - Записать причину
   - Ожидать ручного вмешательства
```

### Логирование
- Каждая задача: начало/конец в лог-файл
- Ошибки сборки: полный вывод + анализ
- Решения: описание применённых исправлений

### Отчётность
- После каждой задачи: обновление статуса
- После каждой сборки: exit code + время
- При остановке: полный отчёт о проблеме
