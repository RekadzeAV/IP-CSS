## 🐛 Частые Проблемы и Решения

### Проблема 1: Камеры не обнаружены

**Решение:**
```powershell
# Проверьте подсеть
.\scripts\discover-rtsp-cameras.ps1 -Subnet 10.0.0.0/24

# Проверьте вручную
Test-NetConnection -ComputerName 192.168.1.100 -Port 554
```

### Проблема 2: Authentication Failed

**Решение:**
```powershell
# Обновите пароли в конфигурации
notepad config\test-cameras-local-network.example.json
```

### Проблема 3: API Server Not Available

**Решение:**
```powershell
# Запустите сервер
.\gradlew :server:api:run

# Проверьте
curl http://localhost:8080/api/v1/health
```
