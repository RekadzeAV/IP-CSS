## ⚠️ Возможные Причины

### 1. Камеры Физически Отсутствуют:
- IP-адреса 192.168.10.100-104 не назначены устройствам
- Камеры не подключены к сети

### 2. Камеры На Других IP:
- Реальные IP-адреса камер отличаются от конфигурации
- Требуется сканирование для обнаружения реальных адресов

### 3. Брандмауэр/Сетевые Ограничения:
- Порт 554 заблокирован на камерах
- Межсетевой экран блокирует RTSP трафик

### 4. Камеры Выключены:
- Устройства не работают
- Нет питания

## 📋 Рекомендации

### Для Тестирования Камер:

1. **Проверить Физическое Наличие:**
   ```powershell
   # Пинг шлюза
   Test-Connection 192.168.10.1 -Count 2
   
   # Проверка ARP таблицы
   Get-NetNeighbor -InterfaceAlias "Ethernet"
   ```

2. **Узнать Реальные IP Камер:**
   - Проверить конфигурацию роутера/DHCP сервера
   - Использовать сканер сети (nmap, Advanced IP Scanner)

3. **Использовать RTSP Mock-Server:**
   ```bash
   docker run -d --name rtsp-mock \
     -p 8554:8554 \
     bluenviron/mediamtx
   ```

4. **Настроить Тестовые IP:**
   - Обновить конфигурацию с реальными IP камер
   - Или использовать доступные устройства
