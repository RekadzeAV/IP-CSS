## Рекомендации

### 1. Настройка ONVIF прав (приоритет: высокий)

Для 5 камер (192.168.10.17, 20-22, 26):
1. Зайти в веб-интерфейс камеры по HTTP (порт 80/8080)
2. Перейти: **Настройки → Network → ONVIF → Users**
3. Выбрать пользователя `survival`
4. Дать права на:
   - ✅ **Events** (GetEventProperties)
   - ✅ **PullPoint** (CreatePullPoint)
5. Сохранить и перезагрузить камеру

### 2. Установка FFmpeg (приоритет: средний)

```powershell
choco install ffmpeg

# Проверить установку
ffmpeg -version

# Запустить тесты HLS сегментации
.\gradlew.bat :core:network:desktopTest --tests "*JvmHlsSegmenterTest*"
```

### 3. Long-run тестирование (приоритет: низкий)

Запустить после настройки прав:
```powershell
.\scripts\video-e2e-go-no-go.ps1 `
  -RunNetworkSmoke `
  -RunLongRunMatrix `
  -NetworkSmokeConfigPath "config\test-cameras.local.json" `
  -OutputDir "release-build\test\e2e-20260527"
```
