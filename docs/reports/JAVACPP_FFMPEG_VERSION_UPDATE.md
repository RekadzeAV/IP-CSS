## 🚀 Рекомендуемое обновление

### Вариант 1: Обновление до последней стабильной версии

```kotlin
implementation("org.bytedeco:ffmpeg-platform:6.1-1.5.13")
```

**Преимущества:**
- ✅ Исправления багов

- ✅ Возможные исправления проблем с типами JavaCPP

**Риски:**
- ⚠️ Возможны изменения в API
- ⚠️ Требуется тестирование

**Преимущества:**

---

## 🔧 План обновления

1. ✅ Проверить актуальные версии
2. ⏳ Обновить зависимости в `core/network/build.gradle.kts`
3. ⏳ Синхронизировать версии (javacv и ffmpeg-platform должны иметь одинаковую версию JavaCPP)
4. ⏳ Проверить компиляцию
5. ⏳ Протестировать функциональность

---

## ⚠️ Важные замечания

1. **Синхронизация версий:**
   - Версия JavaCPP в `javacv` и `ffmpeg-platform` должна совпадать
   - Формат: `ffmpeg-<ffmpeg_version>-<javacpp_version>`

2. **Совместимость:**
   - Проверить совместимость с текущим кодом
   - Возможны изменения в сигнатурах функций

3. **Тестирование:**
   - После обновления обязательно протестировать `avcodec_open2`
   - Проверить работу декодера

---

## 📝 Примечания

- Версия `1.5.9` была актуальна в 2023 году
- JavaCPP активно развивается
- Обновление может решить проблему с `avcodec_open2`
