### 3. Лицензирование — iOS Keychain (3 TODO устранены)

**Файл:** `core/license/src/iosMain/.../LicenseManager.ios.kt`

**Реализованные функции:**

1. **`getSecureDeviceFingerprint()`** ✅
   - identifierForVendor UUID
   - Комбинирование с model и systemVersion
   - SHA-256 хеширование через CommonCrypto
   - CC_SHA256 для генерации fingerprint

2. **`decryptOfflineCode()`** ✅
   - Полная расшифровка через iOS Keychain Services
   - SecKey для управления ключами
   - AES-256-GCM шифрование
   - Генерация ключа при первом запуске
   - Восстановление ключа из Keychain
   - Извлечение IV и расшифровка данных

3. **`schedulePeriodicCheck()`** ✅
   - Интеграция с BGTaskScheduler
   - Периодическая проверка каждые 24 часа
   - BGAppRefreshTaskRequest для фоновой работы
   - Fallback на немедленную проверку при ошибке

4. **`computeHmacSignature()`** ✅
   - HMAC SHA-256 подпись
   - Keychain для хранения ключей
   - Защита от подделки лицензий

5. **`decryptAESGCM()`** ✅
   - AES-GCM расшифровка через CommonCrypto
   - Извлечение IV из зашифрованных данных
   - Обработка ошибок

**Вспомогательные функции:**
- `getKeyFromKeychain()` — получение ключа из Keychain
- `generateAESKey()` — генерация AES ключа
