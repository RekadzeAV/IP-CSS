## ⚠️ Известные ограничения

### H.265 декодирование

**Проблема:** H.265 требует значительных вычислительных ресурсов для программного декодирования.

**Решение:** Использовать аппаратное декодирование (DXVA2 для Windows, VideoToolbox для macOS).

**Статус:** ⏳ В разработке

### MJPEG без аудио

**Проблема:** Некоторые камеры поддерживают только MJPEG видео без аудио.

**Решение:** Автоматическое определение и обработка video-only потоков.

**Статус:** ✅ Реализовано

### Сетевые задержки

**Проблема:** Высокая задержка сети может вызывать рассинхронизацию AV.

**Решение:** Адаптивная буферизация и AV sync алгоритм.

**Статус:** ✅ Реализовано (<50ms drift)
