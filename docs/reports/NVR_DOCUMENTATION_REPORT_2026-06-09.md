## 🎯 Интеграция с IP-CSS

### План Действий:

#### 1. **Проверка Доступности** ⏸️

```bash
# Ping тест
ping 192.168.10.250

# Проверка веб-интерфейса
curl http://192.168.10.250

# Проверка RTSP
rtsp-client-test 192.168.10.250:554
```

#### 2. **Добавление Камер NVR** ⏸️

```bash
# Через API IP-CSS
POST /api/v1/cameras
{
  "name": "NVR Camera 1",
  "url": "rtsp://192.168.10.250:554/cam1",
  "username": "Kassian",

}
```

