## 🎯 Цель

---

## 📋 Подготовка

### Необходимое оборудование

| Производитель | Модель | Количество | Статус |
|---------------|--------|------------|--------|
| Hikvision | DS-2CDxxxx | 2 | ⏳ |
| Dahua | IPC-HFWxxxx | 1 | ⏳ |
| Axis | M30xx / P32xx | 1 | ⏳ |
| Sony | SNC-CHxxx | 1 | ⏳ |
| HiSilicon | IP Camera | 1 | ⏳ |

**Итого:** 5+ камер

### Конфигурация сети

- Все камеры должны быть в одной сети (192.168.1.x/24)
- Доступ к камерам через RTSP (порт 554)
- Корректные учётные данные (admin/password)

### Конфигурация

**Файл:** `config/test-cameras.rtsp.json`

**Существующие конфигурации (10 камер):**
- 7 реальных камер (Hikvision, Dahua, Axis, Sony, MJPEG, HiSilicon, Generic ONVIF)
- 3 эмулятора (AAC, PCMU, PCMA)

**Необходимо обновить:**
```json
{
  "name": "Hikvision_Office_Main",
  "url": "rtsp://admin:REPLACE_ME@192.168.1.100:554/Streaming/Channels/101",
  "type": "hikvision",
  "audio": true,
  "video_codec": "H.264",
  "audio_codec": "AAC"
}
```

## 🔍 Тестируемые сценарии

### Сценарий 1: Подключение

**Проверяем:**
- [ ] RTSP соединение устанавливается
- [ ] SDP описание корректно
- [ ] Непрерывный поток данных

### Сценарий 2: Видео декодирование

**Проверяем:**
- [ ] H.264 декодирование работает
- [ ] H.265 декодирование работает (если поддерживается камерой)
- [ ] FPS соответствует ожиданиям

### Сценарий 3: Аудио декодирование

**Проверяем:**
- [ ] AAC декодирование работает
- [ ] G.711 (PCMU/PCMA) декодирование работает
- [ ] Качество аудио приемлемое

### Сценарий 4: AV синхронизация

**Проверяем:**
- [ ] Аудио и видео синхронизированы
- [ ] drift <50ms
- [ ] Нет рассинхрона при переподключении

### Сценарий 5: Reconnect

**Проверяем:**
- [ ] Переподключение работает
- [ ] Восстановление потока после разрыва
- [ ] Время reconnect <3 сек
