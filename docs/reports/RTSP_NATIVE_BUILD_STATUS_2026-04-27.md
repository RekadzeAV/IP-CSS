## 🐛 Известные проблемы

### FFmpeg 8.0 API
- Аудио декодирование требует обновления API
- `ch_layout` вместо `channels` (FFmpeg 5.0+)
- Требуется адаптация `audio_decoder.cpp`

### Платформы
- Windows: требуется vcpkg + MSVC/MinGW
- Linux: требуется pkg-config + dev пакеты
- macOS: требуется Homebrew + Xcode
