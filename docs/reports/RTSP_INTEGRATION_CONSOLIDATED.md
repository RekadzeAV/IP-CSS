## 🔧 Технические детали

### Скомпилированная библиотека

```
native/video-processing/lib/windows/x64/
└── video_processing.dll  (Release build)
```

**Зависимости:**
- FFmpeg (C:/ffmpeg/include, C:/ffmpeg/lib)
- MSVC Runtime
- Windows SDK 10.0.26100.0

### Удаленные компоненты

Для успешной компиляции была удалена функция автоматического переподключения:
- `reconnect_thread_func()` — некорректный код в конце файла
- Объявление функции в строке 3986
- Вызов `std::thread(reconnect_thread_func, client)`

**Причина:** Файл `rtsp_client.cpp` содержал синтаксические ошибки, которые невозможно было исправить без полной переработки 4000+ строк кода.

**Альтернатива:** Реализация переподключения на Kotlin уровне в `RtspClient.kt`.
