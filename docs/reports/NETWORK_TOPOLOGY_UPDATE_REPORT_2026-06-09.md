### 2. ✅ Добавлена Детальная Настройка NAS

**Секция 2.1 - Настройка NAS Хранилища**

**8 шагов настройки:**

1. **Определить модель NAS:**
   - Подключение к веб-интерфейсу
   - Проверка доступности

2. **Проверить LDAP доступность:**
   ```bash
   ldapsearch -x -H ldap://192.168.10.37 -b "dc=surveillance,dc=local"
   ```

3. **Создать SMB/NFS шары:**
   ```bash
   # SMB (Windows)
   New-SmbShare -Name "recordings" -Path "/storage/recordings"
   
   # NFS (Linux)
   echo "/storage/recordings 192.168.10.0/24(rw,sync)" >> /etc/exports
   ```

4. **Настроить права доступа:**
   - Создание LDAP пользователя для IP-CSS
   - Настройка групповых прав

5. **Интегрировать LDAP с IP-CSS:**
   ```yaml
   AUTH_LDAP_SERVER: "ldap://192.168.10.37:389"
   AUTH_LDAP_BASE_DN: "dc=surveillance,dc=local"
   AUTH_LDAP_BIND_DN: "cn=admin,dc=surveillance,dc=local"
   ```

6. **Монтирование NAS:**
   ```bash
   # SMB mount
   net use Z: \\192.168.10.37\recordings
   
   # NFS mount
   mount -t nfs 192.168.10.37:/storage/recordings /storage/recordings
   ```

7. **Автоматическая синхронизация:**
   ```bash
   crontab -e
   0 2 * * * rsync -avz /storage/recordings/ backup:/backup/
   ```

8. **Проверка доступности:**
   ```bash
   touch /storage/recordings/test_file
   ls -la /storage/recordings/
   ```

**Результат настройки NAS:**
- ✅ NAS подключён и доступен
- ✅ LDAP аутентификация работает
- ✅ Записи сохраняются на NAS
- ✅ IP-CSS использует LDAP для авторизации

### 3. ✅ Добавлена Детальная Настройка Raspberry Pi

**Секция 2.2 - Настройка Raspberry Pi Edge**

**10 шагов настройки:**

1. **Установка Raspberry Pi OS:**
   - Скачать образ
   - Записать на SD карту
   - Включить SSH

2. **Первый Запуск и Настройка Сети:**
   ```bash
   ssh pi@192.168.10.45
   # Настройка статического IP в /etc/dhcpcd.conf
   ```

3. **Установка Пакетов:**
   ```bash
   apt install -y ffmpeg gstreamer1.0-tools nginx curl git
   # Опционально: Docker
   ```

4. **Настройка RTSP Прокси (mediamtx):**
   - Скачать mediamtx
   - Настроить конфигурацию `mediamtx.yml`
   - Запустить сервис

5. **Настройка Автозапуска (systemd):**
   ```ini
   [Unit]
   Description=RTSP Proxy Service
   
   [Service]
   ExecStart=/home/pi/mediamtx/mediamtx
   Restart=always
   
   [Install]
   WantedBy=multi-user.target
   ```

6. **Настройка Локальной Записи:**
   - Создать скрипт записи с ffmpeg
   - Настроить расписание записей

7. **Интеграция с NAS:**
   ```bash
   mount -t nfs 192.168.10.37:/storage/recordings /mnt/nas-recordings
   # Добавить в /etc/fstab для автомонтирования
   ```

8. **Настройка AI (опционально):**
   - Установка OpenCV + TensorFlow
   - Скрипт детекции движения

9. **Настройка Мониторинга:**
   ```bash
   apt install -y htop iotop nethogs
   journalctl -u mediamtx -f
   ```

10. **Тестирование:**
    ```bash
    ffprobe rtsp://192.168.10.45:8554/cam1
    ls -lh /var/recordings/
    top -b -n 1
    ```

- ✅ RTSP прокси работает
