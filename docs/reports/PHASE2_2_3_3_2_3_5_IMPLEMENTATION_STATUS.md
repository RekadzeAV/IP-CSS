## 📊 Задача 2.3.3: Графики и отчёты (статистика, экспорт CSV/PDF)

### Реализованный функционал

#### Веб-интерфейс (`/reports`)

Создана полнофункциональная страница отчётов с:

1. **Фильтрация данных:**
   - Выбор камеры (или все камеры)
   - Выбор периода (день, неделя, месяц, год)
   - Live обновление статистики

2. **Вкладки отчётов:**
   - **Обзор** — общая статистика с графиками
     - Карточки ключевых метрик (события, записи, номера)
     - Динамика событий и записей (линейный график)
     - Распределение событий по типу (pie chart)
   
   - **События** — детализация по событиям
     - Гистограмма событий по типу
     - Pie chart по серьёзности событий
     - Динамика событий во времени
   
   - **Записи** — статистика записей
     - Всего/активные/завершённые записи
     - Общий объём хранилища
   
   - **Аналитика** — сводка по AI аналитике
     - Распознанные номера (ANPR)

3. **Экспорт отчётов:**
   - **CSV** — события, записи, ANPR
   - **PDF** — дашборд сводка
   - Кнопки экспорта для каждого типа отчёта

4. **Графики и визуализация:**
   - Используется библиотека **Recharts**
   - Линейные графики (LineChart)
   - Столбчатые диаграммы (BarChart)
   - Круговые диаграммы (PieChart)
   - Адаптивные контейнеры (ResponsiveContainer)

### Серверная часть

Серверная часть уже была реализована в файлах:
- `server/api/src/main/kotlin/.../ReportService.kt` — интерфейс
- `server/api/src/main/kotlin/.../ReportServiceImpl.kt` — реализация
- `server/api/src/main/kotlin/.../ReportRoutes.kt` — маршруты

**Доступные типы отчётов:**
- `EVENTS_SUMMARY` — сводка событий
- `RECORDINGS_SUMMARY` — сводка записей
- `LICENSE_PLATES_SUMMARY` — распознанные номера (ANPR)
- `ANALYTICS_DASHBOARD` — общая аналитика

**Форматы экспорта:**
- CSV (текстовый формат с разделителями)
- PDF (простой одностраничный документ)

### Файлы созданы/изменены

**Созданы:**
1. `server/web/src/services/reportService.ts` — сервис для работы с API отчётов
2. `server/web/src/app/reports/page.tsx` — страница отчётов с графиками

**Изменены:**
1. `server/web/src/store/slices/settingsSlice.ts` — добавлено сохранение темы в localStorage

## 🌙 Задача 2.3.5: Тёмная тема

### Реализованный функционал

1. **Поддержка Material UI тем:**
   - Светлая тема (light)
   - Тёмная тема (dark)
   - Переключатель темы в навигационной панели (иконка солнца/луны)

2. **Сохранение предпочтений:**
   - Тема сохраняется в `localStorage` браузера
   - При перезагрузке страницы выбирается сохранённая тема
   - Redux store синхронизируется с localStorage

3. **Автоматическая адаптация:**
   - Все компоненты MUI автоматически адаптируются под тему
   - `CssBaseline` обеспечивает консистентные стили
   - Цвета графиков Recharts автоматически адаптируются

### Файлы изменены

1. `server/web/src/store/slices/settingsSlice.ts`
   - Добавлена логика сохранения/загрузки темы из localStorage
   - Redux actions `toggleTheme` и `setThemeMode` обновляют localStorage

2. `server/web/src/app/providers.tsx`
   - Уже реализована поддержка тем через `ThemeProvider`
   - Тема динамически обновляется при изменении `themeMode` в Redux

3. `server/web/src/components/ThemeSwitcher/ThemeSwitcher.tsx`
   - Уже существовал компонент переключения темы
   - Работает в связке с Redux store

4. `server/web/src/components/Layout/Layout.tsx`
   - Добавлена иконка `AssessmentIcon` для страницы отчётов
   - Добавлен пункт меню "Отчёты"

## 📝 Примечания

1. **Mock data:** Страница отчётов использует mock данные при отсутствии доступного API. В production необходимо реализовать endpoint `/api/v1/analytics/statistics` для получения реальных данных.

2. **Производительность:** Графики оптимизированы для работы с большими объёмами данных через `ResponsiveContainer`.

3. **Мобильная версия:** Страница отчётов адаптивна и корректно отображается на мобильных устройствах.

4. **Доступность:** Все элементы управления доступны через клавиатуру и screen readers.
