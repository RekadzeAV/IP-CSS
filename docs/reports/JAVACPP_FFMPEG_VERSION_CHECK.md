# Проверка версий библиотек JavaCPP FFmpeg

**Дата:** 28 января 2026

## 📦 Текущие версии в проекте

### Найдено в `core/network/build.gradle.kts`:

```kotlin
implementation("org.bytedeco:javacv:1.5.9")
implementation("org.bytedeco:ffmpeg-platform:6.0-1.5.9")
```

**Расшифровка версии:**
- `javacv:1.5.9` - версия JavaCV (обертка над JavaCPP)
- `ffmpeg-platform:6.0-1.5.9` - версия FFmpeg 6.0, собранная для JavaCPP 1.5.9

---

## 🔍 Проблема с avcodec_open2

**Ошибка:** `None of the following candidates is applicable`

**Возможные причины:**
1. **Устаревшая версия JavaCPP** - версия 1.5.9 может иметь проблемы с типами в Kotlin
2. **Несовместимость версий** - несоответствие между версией JavaCV и FFmpeg
3. **Изменения в API JavaCPP** - возможны изменения в сигнатурах функций

---

## 📊 Рекомендации

### 1. Проверить актуальные версии

**JavaCV:**
- Текущая: `1.5.9` (релиз от 2023 года)
- Проверить: https://mvnrepository.com/artifact/org.bytedeco/javacv

**FFmpeg Platform:**
- Текущая: `6.0-1.5.9`
- Проверить: https://mvnrepository.com/artifact/org.bytedeco/ffmpeg-platform

### 2. Возможные обновления

**Последние стабильные версии (на 2024-2025):**
- JavaCV: `1.5.10` или новее
- FFmpeg Platform: `6.1-1.5.10` или новее

**Важно:** При обновлении нужно обновлять обе библиотеки одновременно, так как версии должны совпадать!

### 3. Альтернативные решения

Если обновление не помогает:

1. **Использовать прямые зависимости JavaCPP:**
   ```kotlin
   implementation("org.bytedeco:ffmpeg:6.0-1.5.9")
   implementation("org.bytedeco:javacpp:1.5.9")
   ```

2. **Проверить документацию JavaCPP:**
   - https://github.com/bytedeco/javacpp
   - https://github.com/bytedeco/javacpp-presets

3. **Использовать альтернативный способ вызова:**
   - Через JNI напрямую
   - Через обертку на C++
