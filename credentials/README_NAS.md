## 📝 Структура учётных данных

### Synology NAS (`credentials/.env.nas`)

```env
# Synology NAS RS2416+ Connection
NAS_HOST=192.168.10.38
NAS_PORT=22
NAS_USER=Andrey
NAS_PASSWORD=****

# DSM Web Interface
NAS_WEB_HTTP_PORT=5000
NAS_WEB_HTTPS_PORT=5001
NAS_WEB_URL_HTTP=http://192.168.10.38:5000
NAS_WEB_URL_HTTPS=https://192.168.10.38:5001

# Git Server Credentials
GIT_USER=VSCode
GIT_PASSWORD=****
GIT_PORT=9418
GIT_SSH_PORT=22
GIT_BASE_PATH=/volume1/git

# Docker on NAS (if enabled)
DOCKER_HOST=ssh://Andrey@192.168.10.38:22
```

## 🌐 Доступ к NAS

### SSH подключение
```bash
ssh Andrey@192.168.10.38
```

### DSM Web-интерфейс
- **HTTP:** http://192.168.10.38:5000
- **HTTPS:** https://192.168.10.38:5001

### Git доступ

#### По SSH:
```bash
git clone ssh://Andrey@192.168.10.38:22/volume1/git/IP-CSS.git
```

#### По Git протоколу:
```bash
git clone git://192.168.10.38/IP-CSS.git
```

#### Через веб-интерфейс:
1. Откройте Package Center
2. Установите Git Server
3. Настройте доступ через веб-интерфейс
