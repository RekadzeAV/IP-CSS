# Тестовые камеры для этапов тестирования видеопотока

Для этапов тестирования, где нужен реальный видеопоток с камер, используется локальный конфиг.

## Использование

1. **Шаблон:** `test-cameras.example.json` — формат конфигурации (можно коммитить).
2. **Локальные данные:** `test-cameras.local.json` — реальные IP, логин и пароль камер.  
   Файл **не коммитится** (добавлен в `.gitignore`) и **не входит в сборку** — только для локальной проверки и тестов.

## Формат `test-cameras.local.json`

- `cameras` — массив камер: `id`, `name`, `host`, `rtspPort`, `rtspPath`, `username`, `password`.
- RTSP URL для каждой камеры: `rtsp://username:password@host:rtspPort/rtspPath`.
- В `defaults` можно указать `httpPorts`: камеры могут также отвечать по портам **80**, **8080**, **443** (HTTP/HTTPS, веб-интерфейс, ONVIF и т.д.). При проверке подключения или обнаружении имеет смысл опрашивать и эти порты.
- При необходимости измените `rtspPath` (например `/Streaming/Channels/101`) под ваши камеры.

## Загрузка в тестах

Тесты и скрипты должны читать конфиг только если существует `config/test-cameras.local.json`; при его отсутствии тесты с реальным видеопотоком пропускаются (например, в CI).
